# 0036. しるべ線の終わりを卒業駅から行き先(職業)にし、礎の注意と行先表示の副題をなくす

- ステータス: 承認
- 日付: 2026-10-19

## 文脈

ADR 0033 で、道標を鉄道に見立てた「しるべ線」にした。道のりの終わりは、最後の学期の次の駅番号(SH05 など)を持つ「卒業駅」にし、記念スタンプ(しるべ線、卒業、駅番号)と「卒業駅」の見出しを出した。上の要約は「到着 卒業 SH05」、上に付いてくる帯の終点は「SH05 卒業」にした。礎が柱と同じ学期や後の学期に置かれたときは注意を出し、ADR 0034 でその注意に「柱より前の学期には置けませんでした」を添えた。行先表示の板には、行き先の上に「しるべ線 ・ 各駅停車」と小さく書いた。

高橋さんが手元で本物のアプリを動かして見て、次のように判断した。

- 卒業駅はださい。終わりは、たとえば「組込みエンジニアへ」のように行き先にしたい
- 「柱より後の学期です。柱より前の学期には置けませんでした」は要らない
- 「しるべ線 ・ 各駅停車」は要らない

## 検討した選択肢

行き先にする範囲

1. 道のりの終わり、帯の終点、要約の到着の 3 か所とも行き先にする
2. 道のりの終わりだけ行き先にし、帯と要約は「卒業」のまま

## 決定

高橋さんが選んだ。範囲は 1。

- 道のりの終わりは、スタンプと「卒業駅」をやめ、「〇〇へ」(行き先は推薦が読んだ職業。行先表示の「〇〇 行」と同じ)と「最後の学期のあと、道標はここで終わります」にする
- 帯の終点は、駅番号を付けずに行き先にする。要約は「出発 〇〇 → 到着 行き先」にする
- 最後の学期の駅名標の「次」も、「卒業 →」から「行き先 →」にする(帯と道のりの終わりにそろえる)
- 行き先には駅番号を付けない。駅番号は学期だけに付ける
- 礎の注意(柱と同じ学期です、柱より後の学期です、柱より前の学期には置けませんでした)をなくす。礎の切符の「乗換 → 柱(駅番号 学期)」は残す
- 行先表示の板から「しるべ線 ・ 各駅停車」をなくす
- 乗り換えの柱より前か同じか後かは、注意にしか使っていなかったので、lib からもなくす
- 作成中の画面の道しるべの絵(卒業と始める学期の矢印)は、この判断の外なので今のまま

## 理由

- shirube の行き先は職業で、行先表示も「〇〇 行」と書いている。卒業は学期ではないので、駅にすると見立てが無理をしていた。終わりを行き先にすると、行先表示、要約、帯、道のりの終わりが同じ言葉でつながる
- 礎がどの柱へつながるかと、その柱の駅と学期は「乗換 →」の行で読める。柱より後の礎の多くは下の回生から取れる授業で、ADR 0034 と 0035 で「もう取った」と答えれば道標から外れるようになった
- 「しるべ線 ・ 各駅停車」は飾りで、情報を持たない

## 受け入れたトレードオフ

- 礎が柱より後の学期に置かれていることを、注意としては出さない。乗換の行の学期と見比べて気づいてもらう
- 卒業までの道標であることは、行き先の欄の「道標はここで終わります」と、作成中の画面の絵で伝える

## 再検討する条件

- 礎を柱より後の学期に取ってしまったという声が出たとき(注意を戻すか、配置を変える)
- 行き先の名前が長く、帯の終点に収まらない職業が多いとき
