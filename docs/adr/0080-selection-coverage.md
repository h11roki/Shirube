# 0080. 選び直しは、職業に少しでも役立つ授業を迷っても選ぶ

- ステータス: 承認
- 日付: 2026-10-31

## 文脈

- ADR 0069 で、関係なしを減らすために、選び直しの指示文に「選ぶか迷った授業は答えに含めません。…職業に関係する授業が少なければ、少なく選んで構いません」と足した。開発用で、関係なしは 16.4% → 10.6% に減り、選んだ土台は 1 職業に 0.94 科目減った
- 本番を出して高橋さんが使ったところ、データサイエンティスト(1 回生の春学期から)の道標は 7 科目で、少なく見えた。検索の 20 候補から、特殊講義(深層学習の応用)、数理計画法、情報の数理、信号処理のような、職業に少し役立つ授業も選ばなかった。評価データの期待する科目(4 つ)は全て選んでいたので、判定者の物差しでは取りこぼしていない
- 高橋さんは、道標に出る授業を広く取りたく、職業に少しでもかすっていれば採りたい。関係の薄い授業が少し増えるのは受け入れる

## 検討した選択肢

1. 指示文を、職業に少しでも役立つ授業は迷っても選ぶ向きに替えて、前と後を測る
2. 3 回の選び直しのうち 1 回でも選んだ科目を採る(多数決をやめる)
3. 関係の弱い授業を、柱と礎とは別の 3 段目として出す(domain、API、画面、試験まで変える)

## 決定

高橋さんが 1 を選んだ。

- 指示文の「どちらでもない授業と、選ぶか迷った授業は答えに含めません。数の目安や上限はなく、職業に関係する授業が少なければ、少なく選んで構いません。」を、「どちらでもない授業は答えに含めませんが、職業の仕事に少しでも役立つ授業は、選ぶか迷っても core か foundation に当てはめて選びます。数の目安や上限はありません。」に替える。ADR 0069 の「迷ったら選ばない」と「関係する授業が少なければ少なく選ぶ」の両方が消える。中心と土台の定義と、中心か土台か迷ったときの決まりは変えない
- 測り方と採る条件は、変える前に決める
  - 開発用の 50 職業で、前(組み込みの文面)と後(`SELECTION_PROMPT` に替えた文面、ADR 0068)を `experiment pair` で 1 回ずつ交互に流す(見込み約 140 円、`--budget 160`)
  - ねらいの指標は、1 職業に選んだ中心と、1 職業に選んだ土台。どちらかが、職業ごとの並べ替え検定(ADR 0055)で p < 0.05 で増えれば差あり(2 つのどちらかで決めるので、偶然の差ありの割合は 5% を超えうる。ADR 0054 はねらいを 1 つに絞っていた)
  - 期待する科目を中心に選んだ割合の下がり(点の推定)が 5 ポイント以内であることも条件にする。選ぶ数を増やしても、職業に直結する授業の扱いは崩さない
  - 選んだ科目のうち関係なしと中心の適合率は、上がり下がりを報告する。関係なしが増えるのは受け入れたこととして扱い、採る条件にしない
  - 前と後のそれぞれに `experiment analyze` を流し、期待する科目のうち「候補にあったが選ばなかった」が減ったかを見る
  - 開発用で採る条件を満たしたら、確かめ用の 20 職業で同じ pair を 1 回ずつ流し(見込み約 40 円、ADR 0067)、平均と検定だけを見る。選んだ数の点の推定が増える向きなら採る
- 採ったら、替えた文面を組み込みの文面にする
- 結果(2026-10-31)
  - 開発用(103.6 円、`backend/eval/runs/20261031-112041-selection-coverage-before.json` と `-after.json`): 1 職業に選んだ中心は 4.60 → 5.44(+0.84、区間 +0.42〜+1.26、p < 0.001)で差あり。土台は 3.52 → 3.96(+0.44、p = 0.136)。期待する科目を中心に選んだ割合は 61.6% → 67.5%(+6.0、p = 0.058)で下がらず、採る条件を満たした。選んだ科目のうち関係なしは 12.3% → 16.4%(+4.1、p = 0.027)、中心の適合率は 40.4% → 37.5%(-2.9、p = 0.128)。1 件の費用は 1.00 円 → 1.07 円
  - 関係なしの増えは、学科の授業と合わない職業に集まる(開発用の結果のファイルから数えた、選んだ数 / うち関係なし): テック系スタートアップの起業家 6 / 4 → 13 / 9、ソフトウェアテストエンジニア 2 / 0 → 7 / 4、社内 SE(情報システム部門)8 / 0 → 13 / 3、情報セキュリティエンジニア 4 / 0 → 10 / 2。ADR 0069 が直した職業に、関係なしが戻った
  - 結果のファイルが指す commit 57fff77 は、この ADR を 0079 の番号で書いたときのコミットで、番号を 0080 に付け替えるときに作り直した。コードは 61bb0de と同じで、ADR の番号だけが違う。たどれるように `runs/selection-coverage` のタグを付けた
  - `experiment analyze` では、期待する科目 151 件のうち中心に選んだのが 93 → 102、土台に選んだのが 11 → 5 で、選び直しで落としたのは 24 → 24 のまま。増えた中心は、判定者が土台や関係なしとした授業が主で(中心のうち関係なし 19 → 28)、選び直しで落としていた期待する科目を拾う効き目は無かった
  - 確かめ用(41.1 円、平均と検定だけを見た): 1 職業に選んだ中心は 4.35 → 6.15(+1.80、p = 0.001)、期待する科目を中心に選んだ割合は 69.0% → 89.7%(+20.7、p = 0.004)、関係なしは 15.0% → 17.5%(+2.5、p = 0.337)、中心の適合率は 46.0% → 42.3%(-3.7、p = 0.376)。選ぶ数が増える向きなので、決めた条件どおり採った。開発用の中心は p < 0.001 で、ねらいを 2 つにした分を割った 0.025 の線でも差あり。確かめ用の条件(選ぶ数が増える向き)は、選ぶ数を増やす指示文ならほぼ必ず通るので、確かめ用で拒めなかった。次からは、確かめ用にもねらい以外の指標(関係なしや期待する科目を中心に選んだ割合)の条件を付ける。この回は前と後で読み取りの揺れがあり、検索の再現率 @20 も +3.5 動いたので、期待する科目の +20.7 の全てが指示文の効き目とは限らない

## 理由

- 指示文の 1 文の替えなので、ADR 0069 と同じ物差しで前と後を比べられ、効き目の原因が分かりやすい。費用も変わらない
- 多数決をやめる案は、揺れで 1 回だけ選ばれた授業まで入り、増え方を指示文で制御できない
- 3 段目を作る案は、柱と礎の精度を保てるが、変更が大きい。今回の指示文で足りなければ次に考える

## 受け入れたトレードオフ

- 関係の薄い授業も道標に出る。判定者の物差しの関係なしと中心の適合率は悪くなりうる
- 少しだけ役立つ授業も柱(中心)として出るので、柱の意味が広がる。礎は前提にする柱が要るので、どの柱の前提でもない少し役立つ授業は柱になる
- 学科の授業と合わない職業(起業家、テストエンジニアなど)では、道標の半分ほどが関係の薄い授業になりうる

## 再検討する条件

- 開発用の選んだ科目のうち関係なしが 20% を超えたとき(時刻による揺れが 9 ポイントほどあるので、今の既定どうしを `experiment pair` で 3 回ずつ交互に流した平均で見る)、または関係なしが目立って利用者が道標を信じなくなったとき(3 段目に分ける案を考える)
