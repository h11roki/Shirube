# 0101. 時間割帳は狭い画面でも週の表にし、時限の時刻と教室を出す

- ステータス: 承認
- 日付: 2026-11-09

## 文脈

- 時間割帳の週の時間割は、幅 640px 以上では月〜金 × 時限の表、640px 未満では曜日ごとの一覧にしている(ADR 0056)。0056 は、表を縮めて 5 日を収める案を「曜日の幅が 50px ほどで授業名が切れる」として採らなかった
- 表の時限の列は数字だけで、マスには授業名と、柱か礎とクラスの記号を出している。教室は出していない
- 高橋さんが、学生がふだん使う時間割のアプリの画面(月〜金 × 1〜7 時限の表、時限の列に始まりと終わりの時刻、マスに授業名と教室)を見せ、時間割帳をこのように出すよう求めた
- 教室は時間割表から取り込んであり(2026 年度の 624 コマのうち 602 コマ。全角の「Ｃ３０２」のような書き方)、道標を保存するときの授業の JSON にも入っている。API の結果には出していない
- 時間割表のデータは時限を 1〜6 で数える。立命館の授業時間は 2025 年度から 1 コマ 95 分で、衣笠とびわこ・くさつの文系は第 1〜7 時限、びわこ・くさつの理系(理工・生命・薬)は 50 分の時限 2 つで同じ 95 分のコマを作る(第 1・2 時限が 9:00〜10:35)。どちらでも、n 番目のコマの始まりと終わりは同じ(大学の「学年暦・授業時間」の頁)

## 検討した選択肢

見た目(高橋さんに聞いた)

1. 並べ方だけ合わせる。表の形、時限の時刻、マスの授業名と教室を合わせ、色は今の柱と礎の付箋、角は直角のまま(ADR 0083)
2. 角丸の淡い色の枠にし、授業ごとに色を替える。時間割帳だけ ADR 0083 の見た目の決まりを外れる

教室(高橋さんに聞いた)

1. 出す。API の結果の置いた授業に教室を足す
2. 出さない。frontend だけで済む

## 決定

高橋さんが、見た目は 1、教室は 1 を選んだ。

- 時間割帳の週の時間割は、画面の幅が 20rem(ふつうの文字の大きさで 320px)以上なら月〜金 × 時限の表にする。ふつうの文字の大きさのスマホは全て表になる。ブラウザの文字を大きくして 20rem に満たないときだけ、曜日ごとの一覧(ADR 0056)にする(文字を 200% にした幅 320px と 375px では、1 日の列が 1 字より狭くなり、授業名が隣の曜日にはみ出す。幅の切れ目は rem なので、文字の設定に合わせて動く)。授業名は切らずにマスの中で語の途中でも折り返し、マスの高さを伸ばす(0056 が表を縮める案を採らなかった理由の、名前が切れることは起こさない)
- 道のりの駅の「この学期の時間割を開く」の中の週の時間割は、今までどおり幅 640px 未満では曜日ごとの一覧にする。駅の枠は路線の線と枠の余白のぶん時間割帳より狭く、幅 320px では 1 日の列が 30px ほどになり、授業名が 1〜2 字ずつ折れるため
- 時限の列に、時限の数字と、そのコマの始まりと終わりの時刻を出す(1 限 9:00〜10:35、2 限 10:45〜12:20、3 限 13:10〜14:45、4 限 14:55〜16:30、5 限 16:40〜18:15、6 限 18:25〜20:00、7 限 20:10〜21:45)。時刻は今の対象の立命館の決まりなので、frontend の表示の決まり(`lib/timetable.ts`)に置く。表の行は今までどおり 5 限までと、授業のある一番遅い時限まで
- マスは、授業名(太字)と、その下に柱か礎(予定)の言葉と教室。教室は全角の英数字を半角にして出す(「Ｃ３０２」を「C302」。共有カードと見本の切符の授業名と同じ決まり)。教室の無い授業は言葉だけ。クラスの記号はマスから外し、同じ画面の切符で見せる。クラスをまだ選んでいない授業(切符の「未確定」)は、置いたコマと教室が仮のクラスのものなので、マスにも「クラス未確定」と出す。柱と礎は色だけでなく言葉でも分かるようにする(WCAG 1.4.1)
- API の結果の置いた授業(`PlacedCourseOut`)に `room`(無ければ null)を足す。保存した道標の授業の JSON に入っている教室を出すので、マイグレーションは要らない
- 色と形は今の柱(朱)と礎(紺)の付箋、直角のまま。画像の今日の曜日の印は付けない(道標はこれからの学期の時間割なので)

## 理由

- 学生がふだん見る時間割と同じ並べ方なので、スマホでも週の全体が一目で分かり、どの曜日のどの時間が埋まるかが読める
- 教室と時刻があると、時間割帳をそのまま履修の下書きとして見比べられる
- 見た目の決まり(ADR 0083)を時間割帳だけ外すと、同じ画面の切符や駅名標とずれる

## 受け入れたトレードオフ

- 幅 320px では 1 日の列が 38px ほどで授業名が 2 字ずつ、375px では 50px ほどで 3〜4 字ずつ折れ、マスが縦に伸びる。名前は切らない
- 時刻は立命館の決まりを frontend に置く。他の大学へ広げるときは、時限の時刻を大学ごとのデータにして API で返す(今は道標に大学の区別が無く、API を先に替えても使う所が無い)
- 土曜と日曜に授業があると、表に列が足されて 1 日の列がさらに狭くなる。2026 年度の時間割表には土日の授業が無い
- 教室は道標を作ったときの時間割表のもので、あとで教室が替わっても保存した道標には出ない(時間割表を入れ替えると、もう取ったの答えは時間割表が変わった道標として断る。ADR 0034)

## 再検討する条件

- 狭い画面で授業名が読みにくいと分かったとき(曜日ごとの一覧に戻すか、切り替えを付ける)
- 他の大学へ広げるとき(時刻をデータにする)
