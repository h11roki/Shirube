# 0076. 本番は AWS の新しい登録の無料プランのまま、シドニーで動かす

- ステータス: 承認
- 日付: 2026-10-31

## 文脈

- ADR 0075 で、新しい AWS アカウントのクレジットで EC2 を動かすと決めた。アカウントを作ったところ、2026 年 9 月からの新しい登録(Sign up for AWS (new))になり、無料プランのプロジェクトの地域は、AWS が住所の国から決めていた。候補はオハイオ、ストックホルム、シドニーの 3 つで、日本はシドニーに入り、後から変えられない([AWS Regions for your projects](https://docs.aws.amazon.com/accounts/latest/reference/project-regions.html))
- 東京を使うには、アカウントを有料プランに上げて高度な機能を有効にするか、従来の登録(Sign up for AWS (advanced))で別のアカウントを作るしかない。無料枠の規約では、クレジットを受け取れるのは 1 つのアカウントだけ([AWS Free Tier の規約](https://aws.amazon.com/free/terms/))
- 新しい登録にはルートユーザーが無く(AWS Builder ID がプロジェクトを持つ)、MFA は AWS Settings で付ける([Compare sign-up options](https://docs.aws.amazon.com/accounts/latest/reference/sign-up-for-aws.html))。無料プランは、クレジットを超えて請求されず、6 か月かクレジットを使い切ると閉じる。閉じたあとも 90 日は中身が残り、そのあいだに有料プランに上げれば戻せる([Choosing a plan](https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/free-tier-plans.html))
- シドニーの t4g.small、ディスク 20GB、固定の IP で月 21 ドルほどかかるので、登録で付く 100 ドルのクレジットは 2027 年 3 月の下旬に尽き、無料プランの期限(登録の 2026-10-31 から 6 か月、2027 年 4 月の末)より先に閉じる。活動をこなすとクレジットが最大 100 ドル足され、そのときは期限が先に来る
- 本番の DB には、利用者の番号(Google の sub)、道標、もう取ったと答えた授業、Caddy のログの IP アドレスが残る。今のプライバシーポリシーは、サーバーがどの国にあるかを書いていない

## 検討した選択肢

- 今の無料プランのまま、シドニーで動かす
- 今のアカウントを有料プランに上げ、高度な機能を有効にして東京で動かす(クレジットで 5 か月ほどは 0 円。そのあとは月 3,000 円前後がカードに請求される。元に戻せず、使用額の上限も付けられない)
- 従来の登録で別のアカウントを作り、東京で動かす(クレジットが付かず、初月から月 3,000 円前後)

## 決定

高橋さんが、今の無料プランのまま、シドニーで動かすことを選んだ。

- EC2 と Elastic IP は、プロジェクトの地域のシドニー(`ap-southeast-2`)に作る。サーバーの構成と手順は ADR 0075 のまま
- プライバシーポリシーに、データを米国の事業者(AWS)のオーストラリア(シドニー)のサーバーに保存することと、オーストラリアの制度(Privacy Act 1988 とオーストラリアのプライバシー原則)と米国の制度(包括的な連邦の法律が無く、分野ごとの連邦の法律と州の法律がある)を書き足す。個人情報保護法の安全管理措置で、外国で個人データを扱うときは、サーバーのある国とクラウドの事業者のある国の制度を把握し、本人が知りうる状態に置くことになっているため
- 無料プランが閉じてサイトが止まらないよう、閉じる時期を見込みで決め、その前に有料プランに上げて続けるかを決める。見込みではクレジットが 2027 年 3 月の下旬に尽きるので、3 月の初めまでに決める
- 見込みが外れたときに気づけるよう、2 つで見張る。Budgets で、クレジットを差し引く前の使用額に月 25 ドルの予算の通知を付け、見込み(月 21 ドル)より速く減る異常を知る。月に 1 度、コンソールのホームでクレジットの残りと残りの日数を見て、見込みとずれていたら決める時期を前に寄せる。予算の通知はクレジットの残りを見ないので、残りと期限は月に 1 度の確かめで見る
- MFA は AWS Settings で付ける

## 理由

- 無料プランなら、クレジットが尽きるまで(5 か月ほど)費用が 0 円で、請求が起きる余地も無い。費用を抑えたいという高橋さんの方針に合う
- 日本からの 1 往復は東京より 0.1 秒ほど延び、ページを開くたびに数往復が重なって数百ミリ秒遅くなる。ポートフォリオとして見てもらうには許せる遅さで、道標を作るのは 20 秒ほどかかり、OpenAI への往復ももともと海外なので、作るときの響きは小さい
- 有料プランに上げる案は 5 か月ほどは同じく 0 円だが、元に戻せず、使用額の上限を付けられないまま請求が始まりうる

## 受け入れたトレードオフ

- ページを開くたびに、東京より数百ミリ秒遅い
- 利用者のデータがオーストラリアに置かれる。ポリシーで知らせる
- 無料プランは 6 か月かクレジットを使い切ると閉じる。月に 1 度の確かめを忘れると、見込みより早く閉じたときに気づかずサイトが止まる。東京に移すなら、高度な機能を有効にしてから、東京にサーバーを作り直し、バックアップから DB を戻し、DuckDNS の向き先を替える

## 再検討する条件

- 2027 年 3 月の初めか、月に 1 度の確かめで見込みより早く閉じそうと分かったとき(有料プランに上げて続けるか、止めるか、ほかに移るか)
- 遅さが使い心地の問題になったとき
