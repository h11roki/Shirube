# 0047. トップの見出しの横に共有カードと同じ授業の切符 2 枚を置き、開いたときに配って柱の判を押し、マウスを乗せると持ち上げる

- ステータス: 承認(切符の券面は 0083 で、柱と礎を判子で示し地紋と通し番号を刷る形に替え、柔らかい影をやめて、持ち上げは位置と傾きだけにした。見本を作り直して切符の授業を替えたことは末尾の追記)
- 日付: 2026-10-22

## 文脈

ADR 0046 で、共有カード(OG 画像)の右に、見本の道標の授業の切符 2 枚(柱「ＡＩ・機械学習」、礎「電子情報基礎数学」)を描いた。高橋さんは、トップの画面(「履修に迷ったら、なりたい職業から。」)のカードに動きを付けたいとした。共有カードは止まった画像で、X は動く画像でも最初の 1 コマしか使わず、LINE などのリンクの絵も止まって出るので、カードそのものを動かしても届かない。トップには見出しと下の一文の横に何も無く、共有カードから来た人は、カードで見た切符をトップで見られない。

## 検討した選択肢

動き方は、試作のページ(パソコンとスマホの幅、動きを減らす設定の見え方)で 4 通りを比べた。

1. 配って判を押す: 開いたとき、奥の礎、手前の柱の順に切符が滑り込み、最後に柱の判がポンと押されて止まる(約 1.3 秒、一度だけ)
2. 配るだけ: 2 枚が順に滑り込んで止まる(約 0.9 秒)
3. めくる: 2 枚が裏から表へめくれて現れる(約 0.8 秒)
4. 触れると持ち上がる: 配ったあと、マウスを乗せると 2 枚が少し開いて持ち上がり、マウスの向きに傾く

スマホでの置き方は、見出しの下に小さく置く、スマホでは出さない、ログイン前だけ出す(ログインの確かめが終わるまで切符を出せず、並びがあとからずれる)の 3 つを比べた。

## 決定

高橋さんが、1 と 4 を合わせる形と、スマホでは見出しの下に小さく置く形を選んだ。

- トップの見出しと下の一文の横(幅 768px 以上)に、それより狭い画面では下に、共有カードと同じ切符 2 枚を置く。中身は見本の道標(`src/lib/sample-plan.ts`)から引き、理由は最後の一文だけを載せる。形は結果の画面の切符と同じ(役割の札、授業名、理由、点線の先の半券にコマと単位、柱には朱の丸い判)
- 2 枚は上から順に並べ、手前の柱の切符を奥の礎の切符のすぐ下に少し重ねる。共有カードと同じく、奥の切符の文字(理由、コマ、単位)を隠さない。切符の幅と余白は rem で決め、ブラウザの文字の大きさを変えても形が崩れない。列の幅より広くなるときは、切符を列の幅まで細くして中の文字を折り返す(画面を横にはみ出さない)
- 切符の下に「見本 ── データサイエンティスト」と小さく添える(ログイン前のトップの下に並ぶ見本の道標の見出しと同じ書き方)。切符はログインしたあとのトップにも出るので、自分への推薦と読み違えないようにする
- 開いたときに一度だけ、奥の礎、手前の柱の順に切符を配り、最後に柱の判を押す。そのあとは、マウスを乗せたときだけ 2 枚が少し開いて持ち上がり、マウスの向きに傾く。マウスの無いスマホやタブレットでは、配るところまで。傾けるのは、ポインターがマウスで、画面の主な入力がマウスを乗せられる(`hover: hover`)ときだけにし、持ち上げる CSS(`group-hover:`)と同じ条件にする
- 配る、判を押す動きの遅れは、使う側(`HeroTickets`)で名前の付いた定数から付ける。アニメーションのトークンは今のトークンと同じく遅れを持たない。動き終わったあとは効果を残さない(`animation-fill-mode: backwards`。合成のレイヤーを残さない)
- 動きを減らす設定では、切符は初めから止まった形で出て、マウスを乗せても動かない(`motion-safe:`、ADR 0031 からの決まり)
- 切符は飾りなので、読み上げからは隠す(`aria-hidden`)。見出しと下の一文が同じことを言う
- 切符はサーバーで描き、マウスの動きを追う部分だけをクライアントの部品(`Tilt`)にする(見本の道標のデータを JavaScript に入れない)。傾きは、傾かない外側の箱で測る
- 授業名は、共有カードと同じく全角の英字と数字だけを半角で見せる(「ＡＩ・機械学習」を「AI・機械学習」。ローマ数字や括弧などは変えない)。理由は最後の一文だけを載せる(「！？」のように続く記号と、閉じ括弧や閉じ引用符は一文に含める)
- 横に並べるため、トップの見出しの大きさを、スマホ 30px、幅 640px から 36px、1024px から 48px にする(今は 640px から 48px)。パソコンでも見出しは「、」の後ろで 2 行になり、共有カードと同じ折り返しになる

## 理由

- 共有カードから来た人が、カードで見た切符がトップで動くのを見るので、カードとトップがつながる
- 動くのは開いたときの一度だけ(約 1.3 秒)で、止まったあとはマウスを乗せない限り動かないので、入力の邪魔をしない。動き続ける飾りには止める手段が要る(WCAG 2.2.2)
- 柱の判は結果の画面の切符と同じ印で、押す動きが「柱」を目立たせる

## 受け入れたトレードオフ

- トップの上の方に部品が 1 つ増える。スマホでは見出しの下に約 240px ぶん(切符 2 枚と見本の断り)、3 つの手順と入力の欄が下がる
- 見出しは幅 640px から 1023px で今より小さくなる(48px から 36px)。広い画面で見出しが 1 行に収まることは無くなる(ADR 0046 の受け入れたトレードオフは、この ADR で変わった)
- 同じ切符は、ログイン前のトップの下の方の見本の道標にも並ぶので、ログイン前は 2 度出る
- 切符の中身は見本の道標から引くので、見本を作り直すと変わる。共有カードの絵は止まった画像なので、カードの切符の授業名、理由、コマ、単位と、代替の文の授業名と柱の理由が、見本の切符と同じかをテストが確かめる(ずれたらカードを撮り直す。ADR 0046 の「見本を作り直しても変わらない」は、この ADR で変わった)
- 傾きの角度はマウスの位置から決まるので、Tailwind のクラスでは書けず、`Tilt` が React の `style` で CSS の変数として渡す(「部品は Tailwind だけで書く」の例外。角度を使う変形はクラスで書く)。動きを減らす設定では角度を渡さない
- トップの切符は、結果の画面の切符を大きくした触れない絵で、部品は共有しない。半券の切り欠きと柱の判のクラスだけを共有する(`TICKET_NOTCH`、`TICKET_STAMP`)ので、切符の見た目を変えるときは 2 か所(と共有カード)を直す
- トップの切符の授業名は半角の「AI」で、その下の見本の道標(実際の出力のまま)は全角の「ＡＩ」になる。アプリ全体で英数字を半角で見せるかは別に決める

## 再検討する条件

- 見本の道標を替えて、切符に向く柱と礎の授業が無くなったとき
- トップの表示が遅くなったとき

## 追記(2026-11-08、見本の作り直し)

ADR 0031 の追記で見本の道標を今の設定で作り直し、前の切符の授業(柱「ＡＩ・機械学習」、礎「電子情報基礎数学」)のうち、電子情報基礎数学が見本から無くなった。再検討する条件の「切符に向く柱と礎の授業が無くなったとき」にあたるので、切符の 2 枚を選び直した。

- 礎は「情報処理」(柱「情報処理演習」の前提、木 2、2 単位)にした。礎 3 科目はどれもコマがあるが、切符に載せる理由の最後の一文が、どの柱の何に要るかを名指ししているのはこれだけだった(応用Cプログラミングは「演習課題の実装に効く。」、データ構造とアルゴリズムは柱を名指ししない長い一文)。応用Cプログラミングは、共有カードの切符の幅では授業名が語の途中で折れた
- 柱は「確率統計」(月 4、2 単位)にした。理由の最後の一文は「データのばらつきを数値で扱える。」で、データサイエンティストに要る力だと一目で分かる。ほかの柱は、コマが無い(データエンジニアリング基礎、データサイエンス・AI基礎)か、理由の最後の一文が職業とのつながりを言わない(ＡＩ・機械学習の「画像中心の学習で実装も扱う。」)か、礎の情報処理が乗り入れる柱で、2 枚が同じことを言う(情報処理演習)
- 2 枚は前と同じく、奥に礎、手前に柱を置く。礎の理由は 4 行になるので、共有カードでは奥の切符を上げ、手前の切符を下げて(奥は 132px から 112px、手前は 296px から 326px)、奥の切符の理由を手前の切符で隠さないようにした
- 柱の理由の一文(16 字)は、トップでも共有カードでも 1 行に入らず、「る。」だけが 2 行目に残った。トップの切符の理由を、授業名と同じくサーバーで語に分けて(`wordsOf`)`Phrases` で語の切れ目でだけ折り、`text-wrap: balance` で行の長さをそろえる(「データのばらつきを / 数値で扱える。」)。共有カードは同じ語の切れ目に `<wbr />` を入れて `keep-all` にし、カードの理由の語の切れ目がトップと同じかをテストが確かめる。balance は Chromium、Safari、Firefox が対応し、対応しないブラウザでは語の切れ目で今までどおりに折れる
- 共有カードの代替の文と画像を撮り直した。カードの切符が見本の切符と同じかは、これまでどおりテストが確かめる
