# 0071. 小さい文字の大きさは rem でテーマに名前を付けて書き、ブラウザの文字の設定に従わせる

- ステータス: 承認
- 日付: 2026-10-26

## 文脈

- ADR 0070 で、文字 200% の試験をブラウザの既定の文字の大きさを 2 倍にして流すことにした。そのとき、px で書いた文字はブラウザの文字の設定で大きくならないと分かった(ADR 0070 の受け入れたトレードオフ)
- px で書いた文字は 3 つの大きさで 20 か所ある。11px が 14 か所(切符の半券のラベル、柱と礎の札、駅名標の始発の札と読み、帯の駅名、出発と到着の札、ロゴの横の「道標」、学期のタブの番号、週の時間割の補足)、11.5px が 1 か所(駅名標の下の前後の学期)、13px が 5 か所(切符の理由、非公式の注意書き、技能の一覧、学期のタブ、続けて取る授業)
- ほかに道しるべの絵(SVG)の中の 2 か所が 11px。SVG の中の大きさは viewBox の単位で、絵の幅(rem)と一緒に大きくなる
- 文字の設定で大きくした利用者には、切符の理由や注意書きなど、読む量の多い文字ほど小さいまま残っていた。WCAG 1.4.4 は画面の拡大で満たせるが、文字の設定で読む人にも同じに大きくしたい

## 検討した選択肢

1. テーマ(`globals.css` の `@theme`)に rem の大きさの名前を付け、部品はその名前で書く
2. 部品の中で rem の任意の値(`text-[0.6875rem]`)に書き換える
3. px のままにする

## 決定

高橋さんが 1 を選んだ。

- 名前は役割で付ける。`text-label`(0.6875rem、11px。札や欄の小さいラベル)、`text-direction`(0.71875rem、11.5px。駅名標の下の前後の学期)、`text-fine`(0.8125rem、13px。理由、注意書き、補足)
- 色の名前(`note` など)と重なる名前は使わない。Tailwind の `text-<名前>` は色と大きさで同じ形になる
- 行の高さはテーマに書かず、今と同じに親から継ぐ
- SVG の中の文字は px のままにする。rem にすると絵の幅と文字の両方が大きくなり、4 倍になる
- トップの見本の切符(ADR 0047)が rem の任意の値で同じ大きさを書いていた 3 か所(`text-[0.6875rem]` と `md:text-[0.8125rem]`)も名前にする
- これから小さい文字を書くときは、この名前か Tailwind の大きさを使う。1 か所だけの大きさ(見本の切符の授業名と判など)は rem の任意の値でよい。どの文字も px では書かない
- 字と一緒に大きくなる飾り(rem で大きさを決めた路線の点、段の丸、手順の丸、切符の切り欠き)の位置も rem で書く。px で書いていた帯の線、道のりの駅の点と線、作成中の段の線、トップの手順の線、切符の切り欠きの 5 か所を直す。切り欠きは点線の枠(2px)の真ん中に置くので `calc(0.5rem+1px)`、段の線は太さ 3px のまま丸の真ん中に置くので `calc(0.625rem-1.5px)` にする。枠線の太さは px のまま

## 理由

- 大きさを 1 か所で決め、名前で役割が分かる。同じ値が 20 か所に散らない
- ふだんの文字(16px)では今と同じ大きさになり、見た目は変わらない
- ADR 0070 の試験が、これらの文字も 2 倍にして確かめるようになる

## 受け入れたトレードオフ

- 名前の付け方を決める手間と、3 つの大きさの使い分けを守る手間がある
- 文字の設定で大きくすると、今まで小さいまま収まっていた半券や札の文字も大きくなり、並びが崩れうる。ADR 0070 の試験で見る
- 名前の無い大きさが要るときは、テーマに足すかどうかをその都度決める
- ブラウザの既定の文字を 16px より小さくした利用者には、`text-label` が 11px より小さくなる(ADR 0056 の 11px の下限はふだんの文字での決まり)。利用者の設定に従うので受け入れる
- `text-direction` は 1 か所でしか使わない。11px に寄せると駅名標の見た目が変わり、任意の値で書くと決まりから外れるので、名前を置く

## 再検討する条件

- 小さい文字の大きさを見直すとき(ADR 0056 の 11px の下限を含めて)
- 4 つ目の大きさが要るとき
