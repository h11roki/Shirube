# 0005. シラバスはセクション単位でチャンク分割する

- ステータス: 承認
- 日付: 2026-10-14

## 文脈

シラバスは 授業の概要 / 到達目標 / 授業スケジュール / 成績評価 / 教科書 などの決まった見出しを持つ。検索クエリは職業から導いたスキルの語彙で、授業の語彙とずれる。各授業に「取るべき理由」を付ける必要がある。

## 検討した選択肢

1. 科目1件を1チャンク
2. セクション単位(概要 / 到達目標 / 授業計画 を別チャンク)
3. 固定長トークン窓(オーバーラップ付き)

## 決定

セクション単位。各チャンクの先頭に科目名を付ける。成績評価・教科書など定型部は埋め込まない。検索結果はチャンクから科目に集約し、科目のスコアは所属チャンクの最大値とする。

## 理由

- 特定スキルに触れる1セクションが、長い授業計画の中に埋もれない
- ヒットしたセクションをそのまま理由文の根拠として引用できる
- 固定長窓は見出し境界を無視して切るため、構造化された文書では精度も説明性も落ちる

## 受け入れたトレードオフ

- チャンクから科目への集約処理が要る
- 科目あたりのベクトル数が増える(3〜5件)

## 再検討する条件

- 評価用データ(職業10件分の正解科目)で再現率が目標に届かないとき。その場合は LLM でスキルを授業概要風の文に言い換えてから検索する方法を先に試す
