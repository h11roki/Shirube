# 0079. 作成中の画面の待ち時間は、行先表示と同じ板の案内板で出す

- ステータス: 承認
- 日付: 2026-10-31

## 文脈

- ADR 0031 で、作成中の画面はページを開いてからの待ち時間を秒で数えると決め、その下に「ふだん 10〜30 秒で終わります。このページを開いたままお待ちください。」と書いていた
- 本番を出して高橋さんが使ったところ、この一文の見た目がださかった
- 道標は worker が作るので(ADR 0029)、ページを閉じても作り続け、「自分の道標」の一覧に出る。「このページを開いたまま」は要らない

## 検討した選択肢

- 文をなくし、待ち時間の秒だけを残す
- 文を短くする(「10〜30 秒ほどお待ちください」)
- 駅の発車案内のような案内板にする

## 決定

高橋さんが、案内板にすることを選んだ。

- 「待ち時間」(この画面を開いてからの秒)と「目安 10〜30 秒」を、小さな見出し(字間を空けた細い字)と桁をそろえた太字の数字で並べる。目安は言い切らず、30 秒を超えても壊れて見えないようにする
- 色と形は行先表示と同じ板(`styles.ts` の `PLATE`)にし、明るい見た目でも暗い見た目でも暗い板になる
- 「このページを開いたまま」は外し、「ページを閉じても作り続け、自分の道標に出ます。」と一覧へのリンクを置く
- 画面の文は `labels.ts` に置く

## 理由

- 作成中の画面は、行先表示、道標の看板、路線の駅で組んでいる。待ち時間も同じ見た目の言葉で出すと、まとまって見える
- 閉じてもよいと分かれば、利用者は待たずにほかの画面へ行ける

## 受け入れたトレードオフ

- 待ち時間は、この画面を開いてからの秒で、作り始めてからの秒ではない。閉じて戻ると 0 秒から数え直す(道標の作り始めの時刻を API が返していないため)

## 再検討する条件

- 作り始めてからの時間を出したくなったとき(道標の API に作った時刻を足す)
