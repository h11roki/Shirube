# 0058. 行先表示の板は、幅に合わせて字を縮め、語の切れ目でだけ折り返す

- ステータス: 承認
- 日付: 2026-10-24

## 文脈

テーマ E(ADR 0056)の確かめで残った、行先表示の板の折り返し。

- 行先表示の板(`DestinationPlate`、ADR 0033)は、職業名を明朝の太字 24px(幅 640px 以上は 30px)で「〇〇 行」と出し、`text-balance` で行の長さをそろえる。ログイン前のトップの見本(サーバーで描く)と、結果の画面と作成中の画面(ブラウザで道標を読み込んでから描く)の 3 か所に出る
- 日本語は字のあいだならどこでも折れるので、幅 320px と 375px では、見本の「データサイエンティスト」が「データサイエ / ンティスト 行」と語の途中で折れる。「組込みソフトウェアエンジニア」は「組込みソフトウェ / アエンジニア 行」になる
- 板は読み上げに出ない飾り(aria-hidden)で、行き先は見出しで伝わるので、見た目だけの問題
- 職業名は利用者の入力と LLM の読み取りから来るので、語の切れ目を手で書けない。`Intl.Segmenter`(単語の区切り)は「データ|サイエンティスト」「組込み|ソフトウェア|エンジニア」「半導体|・|LSI| |設計|エンジニア」と分けた
- CSS の `word-break: auto-phrase`(Chromium だけ)も試したが、カタカナの続く語を 1 つの句として扱い、「データサイエンティ / スト」や「組込みソフトウェアエンジ / ニア」と折れた

## 検討した選択肢

4 つの案を、幅 320px と 375px、3 つの職業名で撮って比べた。

1. 字を幅に合わせて縮め(幅 320px で 19px ほど、407px 以上は今の 24px)、語の切れ目でだけ折る。`Intl.Segmenter` で語に分けて `<wbr>` を挟み、`word-break: keep-all` で語の中では折らない。1 語が行に入らないときだけ `overflow-wrap: anywhere` で字のあいだで折る。見本は 1 行に収まり、長い名前は「組込みソフトウェア / エンジニア 行」と折れる
2. 字を幅に合わせて縮めるだけ。CSS だけで済み、見本は 1 行に収まるが、長い名前は語の途中で折れる
3. 語の切れ目でだけ折る(字は今の大きさ)。長い名前は語で折れるが、見本が「データ / サイエンティスト 行」と 2 行になる
4. 今のまま

## 決定

高橋さんが 1 を選んだ。

- 語の分け方を表示の決まりとして `src/lib/` に置き(`splitWords`)、Vitest で確かめる。`Intl.Segmenter` の無いブラウザ(Firefox 124 まで)では分けずに 1 語として返す
- `DestinationPlate` は語のあいだに `<wbr>` を挟み、`word-break: keep-all` と `overflow-wrap: anywhere`、字の大きさを `clamp(1.125rem, 5.9vw, 1.5rem)`(幅 640px 以上は今の 30px)にする。「行」は最後の語とつなげ、行の頭に「行」だけが来ないようにする
- 通しの試験で、幅 320px と 375px の見本の板が 1 行に収まることと、長い職業名のどの語も 2 行にまたがらないことを確かめる

## 理由

- 見本の「データサイエンティスト 行」は幅 320px でも 1 行に収まり、長い名前も語の切れ目で折れる。行先表示は行き先を一目で読ませる飾りなので、語が切れない方が読みやすい
- 語の切れ目を辞書で決めるので、利用者の入力や LLM の読み取りにも手を入れずに効く

## 受け入れたトレードオフ

- 語の切れ目はブラウザやサーバーの辞書(ICU)で決まるので、まれに思っていない所で分かれうる。トップの見本はサーバー(Node)の辞書、結果と作成中の画面はブラウザの辞書で分ける。どちらもサーバーで描いた板をブラウザで描き直さないので、描き直しの食い違いは起きない
- 狭い画面では板の字が少し小さくなる(幅 320px で 24px から 19px ほど)
- `Intl.Segmenter` の無いブラウザでは、名前の中では折らず、行に入らないときだけ字のあいだで折る(今の見え方に近い)

## 再検討する条件

- 語の切れ目がおかしい職業名が見つかったとき
- 結果や作成中の画面の板をサーバーでも描くようにするとき(サーバーとブラウザで語の分け方が違うと、描き直しで食い違う)
