# 0010. 回生を入力し、卒業までの学期ごとの道標を生成する

- ステータス: 承認(始める学期の既定は 0078 で春学期にした)
- 日付: 2026-10-14

## 文脈

最初のバージョンで生成する時間割の範囲として、1学期分 / 1年分 / 卒業までの複数年 の3案があった。

## 検討した選択肢

1. 1学期分(前期か後期を選ぶ)
2. 前期 + 後期の1年分
3. 回生を入力し、卒業までの残り学期全て

## 決定

選択肢3。入力は 職業 / 回生 / 現在の学期(年度と月から自動判定、変更可)。残り学期を列挙し、学期ごとに時間割を組む。Plan は複数の SemesterPlan を持つ。

前提: 将来の学期のシラバスは存在しないため、当年度のシラバスを翌年度以降の代理とみなす。

## 理由

- 「なりたい職業に向けた道標」という価値は、1学期分より卒業までの見通しで強く伝わる

## 受け入れたトレードオフ

- 開講学期・配当回生・単位数を全科目で構造化して取る必要がある
- 翌年度以降の開講内容が変わると道標と実際がずれる。画面に前提を明示する
- 前提科目と卒業要件は制約にせず、表示にとどめる

## 再検討する条件

- 配当回生や開講学期がシラバスから安定して取れないと分かったとき
- 卒業要件を制約に含める要望が出たとき
