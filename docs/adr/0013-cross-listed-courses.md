# 0013. 合併科目は1ページ = 1つの Syllabus とし、主コードと別名で持つ

- ステータス: 承認
- 日付: 2026-10-15

## 文脈

立命館は同じ授業を学部やカリキュラムの年度ごとに別の科目名・授業コードで開講することがある(合併科目)。シラバスのページは1つで、科目名欄に全ての名前が「§」区切りで並ぶ。

```
16806:平和人権フィールドスタディ (GR) § 16807:国際平和交流セミナー(GR)
15264:IR26-POL104 Introduction to Peace Studies(RA) § 15265:IR18‐AE111 Introduction to Peace Studies(RA) § 15266:Introduction to Peace Studies(RA) § 15267:RUIR-1431 Introduction to Peace Studies(RA)
```

検索結果のリンク文字列も同じ形で、リンク先の URL は先頭のコード(主コード)で作られる。2026 年度の電子情報工学科の時間割表 624 コードのうち 97 は主コードでない。最初の取得は先頭のコードだけを索引にしていたため、この 97 コードと、主コードが時間割表に無い 8 ページ分が「見つからない」になった。

## 検討した選択肢

1. 1ページ = 1つの Syllabus。`code` と `title` は主コード、残りを `aliases`(コードと科目名の組)に持つ。索引と保存ファイル名は主コードに揃え、別名のコードで引いても同じページに当たる
2. 1ページ = 1つの Syllabus。`code` と `title` を持たず、コードと科目名の組の列だけを持つ
3. コードごとに Syllabus を複製する

## 決定

選択肢1。

- `Syllabus` と検索結果の行(`ListingRow`)に `aliases` を持たせる
- 生ページの保存先(`RawStore`)は検索結果の索引を「全てのコード → 行」で作り、どのコードで引いても主コードと href(`DetailLink`)を返す。取得は主コードで保存の有無を判定し、詳細ページのファイル名を主コードに揃える。保存済みページを読むときは主コードのファイルを直接開き、無ければ索引で別名を主コードに引き直す。同じコードが別のページに現れたら、そのコードを引いたときに知らせる(他のコードには影響しない)。科目名の途中の「§」は区切りとみなさず、直後に授業コードが続く「§」だけで分ける
- 時間割表との結合は主コードと別名の両方で行う。利用者に見せる科目名は時間割表の科目名を使う(ADR 0012)

## 理由

- ページと Syllabus が1対1なので、チャンクと埋め込み(ADR 0005、0006)が重複せず、検索結果にも同じ授業が複数回出ない
- 保存ファイル名と URL が主コードで一致し、再取得の判定が単純
- 既存の型に項目を足すだけで済み、別名を使わない処理は変わらない

## 受け入れたトレードオフ

- 結合側で別名も引く必要がある。DB では授業コードから Syllabus への対応表を持つ
- 「先頭が主コード」はサイトの表示順に依存する。結合は主コードと別名の両方で行うので順序が変わっても壊れないが、保存ファイル名と保存の有無の判定は主コードに依るため、順序が変わった年度は同じページを新しい主コードで取り直すことになる
- 保存済みページを別名で読むには検索結果の一覧が手元に要る。一覧が無ければ主コードでしか引けない

## 再検討する条件

- 1つの授業コードが複数のページに現れるようになったとき
- 他大学のシラバスで、合併科目がページ単位ではなくコード単位で公開されているとき
