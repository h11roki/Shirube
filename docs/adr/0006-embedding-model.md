# 0006. 埋め込みモデルは text-embedding-3-small を使う

- ステータス: 承認
- 日付: 2026-10-14

## 文脈

対象は日本語のシラバス。1学科で約40万トークン、全学でも約2,000万トークン。LLM は OpenAI API を使う。

## 検討した選択肢

| 選択肢 | 料金 / 100万トークン | 次元 |
|---|---|---|
| text-embedding-3-small | $0.02 | 1536 |
| text-embedding-3-large | $0.13 | 3072(短縮可) |
| 日本語特化オープンモデル(Ruri v3, PLaMo-Embedding 等) | 推論サーバの運用費 | モデル依存 |

## 決定

text-embedding-3-small。モデル名と次元数は設定値で持ち、再埋め込みを CLI 1発で実行できるようにする。

## 理由

- 料金はどの API モデルでも数円〜数百円で判断材料にならない。運用の単純さを優先する
- LLM と同じ API キーで済む
- large は 3072 次元のままでは pgvector のインデックス上限を超え、短縮指定が要る
- オープンモデルは日本語ベンチマークでは上回るが、推論サーバの運用費が API 料金を上回る

## 受け入れたトレードオフ

- 日本語特化モデルより検索精度が劣る可能性がある
- OpenAI への依存が増える

## 再検討する条件

- 評価用データで再現率が目標に届かず、チャンク方式やクエリ言い換えでも改善しないとき
