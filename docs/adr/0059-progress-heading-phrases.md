# 0059. 作成中の画面の見出しは句の切れ目で折る

- ステータス: 承認
- 日付: 2026-10-24

## 文脈

- 行先表示の板の折り返し(ADR 0058)を写真で確かめたとき、作成中の画面の見出し「道標を作っています」が、幅 320px で「道標を作っ / ています」と語の途中で折れていた。見出しは道しるべの絵と並ぶので幅が狭く、明朝の 24px で `text-balance` をかけている
- トップの見出し(ADR 0046 のキャッチフレーズ)と見本の切符の授業名は、`PHRASE_WRAP`(`word-break: auto-phrase` と `overflow-wrap: anywhere`)で句の切れ目で折っている。`auto-phrase` は Chromium だけが対応し、ほかのブラウザでは今の折り方になる
- 見出しは読み上げる文で、折り方は見た目だけに効く

## 検討した選択肢

1. 句の切れ目で折る。見出しに `PHRASE_WRAP` を付ける
2. 板と同じ語の切れ目の決まり(`Intl.Segmenter` と `<wbr>`)を使う。どのブラウザでも語で折れるが、見出しの文は語と助詞が続くので、板より確かめることが多い
3. 今のまま

## 決定

高橋さんが 1 を選んだ。作成中の画面の見出しに `PHRASE_WRAP` を付け、通しの試験で幅 320px と 375px の折れ方を確かめる。

## 理由

- トップの見出しと同じ決まりで、部品を足さずに済む
- 「道標を / 作っています」のように句で折れれば、語の途中で折れない

## 受け入れたトレードオフ

- Chromium のほかでは今の折り方のまま
- 句の切れ目は Chromium の決まりで決まり、こちらでは選べない

## 再検討する条件

- ほかのブラウザで語の途中で折れることが問題になったとき(2 の案)
- ほかの画面の見出しでも語の途中で折れるものが見つかったとき
