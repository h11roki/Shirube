# 0040. 道標に限界の注意とシラバスの出典を出し、原ページの URL は取り込みで保存して見せるときに引く

- ステータス: 承認
- 日付: 2026-10-21

## 文脈

本番は誰でも使える公開にする(ADR 0038)。本番の前の点検で、利用者に道標の限界と出典を伝えていないと分かった。

- 見出しは「卒業までの道標を作る」で、卒業計画そのものに見える。しかし道標は必修、卒業要件、履修の前提を見ていない(ADR 0007、0022、0025)。授業は AI が選ぶので、評価でも選んだ授業の 15〜18% は判定者の誰も挙げなかった(ADR 0023、0031)。画面のどこにも「非公式」「必修」「卒業要件」「確かめて」が無い
- 来年度以降の学期も今年度の時間割で組んでいる(ADR 0010)ことを、画面で伝えていない
- README と CLAUDE.md は「画面に出すシラバス本文は短い引用にとどめ、原ページへリンクする」と決めているが、リンクも出典も無い。API は授業コード(`syllabus_code`)を返すが、画面は使っていない

原ページの URL は `https://syllabus.ritsumei.ac.jp/syllabus/s/r-syllabus/<大学側の ID>/<年度と授業コード>` で、授業コードだけでは作れない。大学側の ID は、取得して保存した検索結果のページ(`backend/data/raw/`)のリンクにあるが、DB には入れていない。

## 検討した選択肢

URL の置き場所

1. 取り込みでシラバスの表に保存し、道標を返すときに授業コードで引いて付ける
2. 道標を作るときに結果の JSON に入れる(結果の版を 4 にする)

注意の出し方

1. 行先表示のすぐ下に、短い注意を常に出す
2. 結果の一番下に注記として出す
3. 結果を初めて開いたときに出し、「分かった」で閉じてもらう

## 決定

高橋さんが選んだ。URL は 1、注意は 1。

- 取り込み(`ingest syllabi`)で、保存した検索結果のページ(授業コードで個別に引いたページも含む)から詳細ページへのリンクを引き、シラバスの表に原ページの URL を保存する(`syllabi.url`、無ければ NULL)。大学のサイトへ取り直しはしない。同じ主コードが別のリンクで 2 か所にあるときや、検索結果ではほかの授業の別名になっているときは、URL を決められないので無しにし、理由を警告に出して、取り込みの終わりに URL の無いページの数と授業コードを出す(URL のために取り込み全体を止めない。2026 年度の保存済みのページではどちらも 0 件で、詳細 530 ページ全てに URL が付く)。検索結果のページが壊れていれば、そのファイルの名前を出して取り込みを止める
- 道標を返す API(`GET /api/v1/plans/{id}` と、もう取ったの PUT と DELETE)は、結果に出る授業の授業コードでシラバスの表から URL を引き、授業ごとに `syllabus_url`(無ければ null)を付ける。引く処理は application のユースケース(`SyllabusLinks`)に置き、科目リポジトリに URL を引くポートを足す
- 授業の切符に「シラバス ↗」のリンクを置き(読み上げでは授業名つき)、新しいタブで原ページを開く
- 結果の画面とトップの見本の行先表示のすぐ下に、次の注意を常に出す: 非公式の参考であること、必修、卒業要件、履修の前提は見ていないこと、授業は AI が選ぶので誤りや作るたびの違いがあること、履修登録の前に大学の履修要項とシラバスで確かめること
- 結果の画面の終わりに出典を書く: 授業の情報は立命館大学のシラバスと時間割表(その年度)によること、来年度以降の学期も今年度の時間割で組んでいること

## 理由

- 表に保存すれば、前に作った道標にもリンクが出て、取り込み直せば新しい URL になる。道標の結果は推薦と配置の記録のまま変えずに済む
- 注意は、道標を読む前に必ず目に入る場所に置く。閉じるまで出す形は、毎回の手間と、閉じたことを覚える仕組みが要る

## 受け入れたトレードオフ

- 道標を返すたびに、シラバスの表への問い合わせが 1 つ増える(作成中のポーリングでは、結果が無いので引かない)
- 取り込み直すまで、URL は NULL のまま。取り込み直すとシラバスの表を年度ごと入れ替えるので、検索のチャンクも消え、`embed` を流し直すまで検索が空になる(保存済みの埋め込みを使うので API は呼ばない)。本番の DB は最初から取り込みと埋め込みを流す
- 検索結果のページを保存していない授業と、検索結果で URL を決められない授業は URL が無い(取り込みの報告で分かる)。検索結果のページが壊れていると、シラバスの取り込み全体が止まる
- 注意が画面の上の方の場所を少し使う

## 再検討する条件

- 大学のシラバスの URL の形が変わったとき
- 必修や卒業要件を道標で扱うようになったとき(注意の文を見直す)
