# 0083. 見た目は今の題材のまま、器を罫と直角に替え、券面を硬券の作法に寄せる

- ステータス: 承認
- 日付: 2026-10-31

## 文脈

- 高橋さんが「UI から AI っぽさを消し、美しいとされるサイトを参考に。ベースは今のまま」とした。今の見た目(ADR 0031、0033 の路線図と切符)は好きで、方向を大きく変える案(駅のサインの規格、年表の誌面、刷り物の版)は好まれなかった
- 私に引きずられないサブエージェントの洗い出しでは、AI っぽさは題材の部品(行先表示、駅名標、切符、判子)ではなく、それを包む器から来ていた: 角の丸い箱と柔らかい影の積み重ね、錠剤形のボタンと札、左に色帯の付いた一覧、字間を空けた朱の小見出し、記号の多さ、です・ます の説明の重ね。生成りの地、明朝の見出し、朱の差し色の組は、AI が作りがちな型としても挙げられている
- 美しいと評価された日本のサイト(白骨温泉(MUUUUU.ORG の SITE OF THE DAY)、暮しの手帖社、叡山電車の観光列車「ひえい」、常陸国ロングトレイル、日本橋 榛原、Works in Progress)と硬券の資料から、3 つの磨き方を作った: 罫の時刻表(器を罫と直角に)、掛け札(縦書きの札で節を示す)、硬券の券面(通し番号、地紋、判)
- 本番と同じビルドに CSS を差し込んだ試作で、全部を重ねた形を別のサブエージェントに精査させた。重ねると行先表示のまわりに同じ情報と罫と小さい灰色の字が積もり、今の良さだった「行先表示 → 要約 → 切符」の流れが濁る、という指摘で、重なりを削った精査版を作った

## 検討した選択肢

1. 罫の時刻表だけ
2. 3 つを全部重ねる
3. 精査版(罫の時刻表を土台に、掛け札は「見本」だけ、券面は番号と地紋と判)

## 決定

高橋さんが 3 を選んだ。

- 罫の役を決める。2px の墨(`ink`、暗い見た目では明るすぎないよう弱める)は塊の始まりに 1 本、1px の `line` は塊の中の区切り、`edge` は触れる物の縁、破線は切り取り線と、空きやまだ通っていない道(空いたコマ、置けなかった授業の欄、作成中のこれからの段)だけ。二重枠は判子のほかに使わない
- 角丸と柔らかい影をやめる。箱、切符、行先表示、駅名標、要約、入力は直角、影は無し(画面に浮く「もう取った」の知らせと、時間割帳の付箋だけは、紙が浮いて見えるよう 2px のずれの影を残す)。ボタンとタブと札の錠剤形もやめ、ボタンは角 2px の四角にする。主のボタンは墨の塗りにし、朱は柱の判子と行先表示の「行」に寄せる。「始発」も朱の塗りをやめて墨の枠
- 見え方の切り替え(道のり / 時間割帳)と学期のタブは、下に路線の色の線を引くタブにする
- 一覧は左の色帯と錠剤形の札をやめ、上に 2px の墨の罫、行ごとに 1px の罫を引き、状態は字の色だけ(作成中は路線の色、完了は墨、失敗は危険の色)
- 字間を空けた朱の小見出しはやめる。結果の画面の「目的地 ── 職業」は行先表示と重なるので消す(入力した職業名と読み取った職業が違うときだけ、〔入力した職業 …〕と出す)。トップの大学名は〔 〕で括った小さな字(`sub` の色)にする。トップの見本は、行先表示の左に接して掛けた縦書きの札「見本」で示す
- 要約は紺の帯の箱をやめ、上 2px・下 1px の罫の間に 3 段で組む: 「(学期) 発 ・ 経由 (スキル)」、「所要 | 計 | 柱 | 礎」、「1 学期 (上限) 単位まで ・ (年度) 年度の時間割」。スキルの「◇」の並びと、要約の下の上限の行は要約に入れる
- 注意書きは直角の 1px の枠の箱にし、要約と同じ幅にする
- 切符の左上の「柱」「礎」の字はやめ、判子で示す。柱は朱の二重円の丸判、礎は紺の二重の角判にし、切符の上の辺に半分かけて押す。傾きは切符ごとに少し変える。読み上げには今の字を残す
- 切符の地に、柱は朱、礎は紺の細い斜線の地紋をごく薄く敷く(色は変数から取り、暗い見た目でも替わる)。半券の下に、道のりの順の通し番号(0001 から、数字だけ)を刷る
- 凡例も判子の形(丸と角)にする
- トップの 3 手順は残し、丸と線を細くする。見本の説明の文は短くする
- 暗い見た目では、罫が太く明るく見えすぎないよう色を合わせ、行先表示の板に縁を付ける
- トップの見本の切符も同じ券面にし、共有カード(OG 画像)も撮り直す(ADR 0046、0047)
- 作り直しは 3 つの PR に分ける: 器と罫、要約と券面、動き(ADR 0084)

## 理由

- 洗い出しで AI っぽさの元だった器だけを替え、題材の部品はそのまま使うので、今の見た目の良さを保てる
- 罫と直角は、参考にしたサイトに共通する作法で、印刷物の落ち着きが出る
- 判子と通し番号と地紋は、切符という題材からしか出てこない細部で、ほかのサイトに無い
- 精査で、重ねすぎると情報と罫が積もると分かったので、役が重なるものは削った

## 受け入れたトレードオフ

- 影をやめるので、切符が地から浮いて見える立体感は減る
- 柱と礎の字を判子に替えるので、判子を知らない人には一目で分かりにくくなりうる(凡例と読み上げで補う)
- 通し番号は、道標の中の並びの番号で、大学の授業コードではない

## 再検討する条件

- 利用者から、判子だけでは柱と礎が分かりにくいと言われたとき
- 授業コードを API で返すようになったとき(通し番号の代わりに刷る)
