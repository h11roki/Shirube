# 0062. 語の端の括弧は、隣の 1 字と折らない組にする

- ステータス: 承認
- 日付: 2026-10-24

## 文脈

- 語や句は `Phrases` が、あいだに読み上げから外した `<wbr>` を挟み、`word-break: keep-all` で語の中を折らず、行より長い語だけ `overflow-wrap: anywhere` で語の中で折る(ADR 0059、0061)
- 語の分け方は開き括弧の前で折る(ADR 0061)ので、「特殊講義（専門）Ⅲ（深層学習の応用）」は「特殊」「講義」「（専門）Ⅲ」「（深層」「学習の」「応用）」に分かれる
- 切符の授業名を通しの試験で確かめると、WebKit は幅 320px で「特殊講義（専門）Ⅲ（ / 深層学習の応用）」と開き括弧のあとで折った。語の中なので `keep-all` で折れないはずだが、WebKit の `keep-all` は開き括弧のあとを折ってよい所として扱う。Chromium と Firefox は括弧の前の `<wbr>` で折る
- 3 つの名前を幅 64px から 320px まで 8px ごとに折ると、WebKit は 63 か所で開き括弧を行の終わりに残した。3 つのエンジンとも、行より長い語を語の中で折るときは、閉じ括弧を行の頭に置いた(「【バスケットボール / 】」)

## 検討した選択肢

1. 語の頭の開き括弧は次の 1 字と、語の終わりの閉じ括弧は前の 1 字と、`white-space: nowrap` の組にする
2. 開き括弧のあとに単語結合子(U+2060)を入れる。WebKit は変わらず開き括弧のあとで折った
3. 語ごとに `white-space: nowrap` にする。WebKit でも語の切れ目でだけ折れるが、行より長い語を折れず、文字を大きくするとはみ出す(ADR 0059 で外した形)
4. WebKit の折れ方を受け入れる

## 決定

1 にする。

- 語を、語の頭に続く開き括弧の全てと次の見た目の 1 字、語の終わりに続く閉じ括弧の全てと前の見た目の 1 字を組にした並び(`bracketRuns`、`src/lib/words.ts`)に分け、`Phrases` が組を `white-space: nowrap` の span で描く。重なった括弧(「（「AI」入門））」)は「（「A」と「門））」を組にする。組が語の全てに届くなら(「(A)」)、語の全てを組にする
- 見た目の 1 字は、`Intl.Segmenter` があれば書記素で、無ければ結合する記号(異体字セレクタ、結合する濁点)を前の字に付けて数える(`splitTail` と共有する)。トップの切符はサーバーで描いてからブラウザで描き直すので、数え方がずれると描き直しが食い違う。絵文字の組は、`Intl.Segmenter` の無いブラウザでは数え方が違う
- 行き先の名前の最後の 1 字を外して「行」「へ」と折らない組にする `splitTail`(ADR 0061)も、最後の語が閉じ括弧で終わるときは括弧の組(閉じ括弧の全てと前の 1 字)を外し、語の全てが組になるとき(「(AI)」)は語の全てを外す。最後の 1 字だけを外すと、前の字と閉じ括弧が別の要素に分かれて組が効かず、語が行より長いと閉じ括弧が行の頭に来うる。職業名には「技術系公務員(電気・情報)」のように閉じ括弧で終わるものがある
- 先の 3 つの名前を同じ幅で折ると、3 つのエンジンとも括弧が行の頭や終わりに残らなかった
- 試験は Vitest で組の分け方を、通しの試験(Chromium と WebKit、ADR 0060)で切符の授業名を確かめる

## 理由

- 括弧と隣の字のあいだだけを折らない組にするので、語のあいだの折り方と、行より長い語を語の中で折ることは変わらない
- 3 つのエンジンで同じ折れ方になる

## 受け入れたトレードオフ

- 組は 2 字なので、行がその 2 字より狭いとはみ出す(幅 64px でも起きなかった)
- 括弧が語の真ん中にあるとき(「（専門）Ⅲ」の「）」)は組にしない。そこで折れるのは、語が行より長いときだけ

## 再検討する条件

- WebKit が `keep-all` の中で開き括弧のあとを折らなくなったとき(開き括弧の組は要らなくなる)
- 括弧のほかに、行の頭や終わりに残る字が見つかったとき
