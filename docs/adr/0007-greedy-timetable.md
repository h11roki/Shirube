# 0007. 時間割は学期ごとに関連度順の貪欲法で組む

- ステータス: 承認
- 日付: 2026-10-14

## 文脈

候補科目は関連度スコア、開講学期、配当回生、単位数、曜日時限(複数コマ・複数クラスあり)を持つ。制約は同一(学期, 曜日, 時限)の重複禁止、配当回生、学期の単位上限、同じ科目を二度入れない。

## 検討した選択肢

1. 関連度順の貪欲法
2. 整数計画(OR-Tools / PuLP)
3. LLM に組ませる

## 決定

貪欲法。学期を時系列に処理し、各学期で「配当回生を満たす・その学期に開講・未採用」の科目をスコア順に並べ、既存コマと衝突せず単位上限内なら採用する。domain の純粋関数として実装し、入出力の型を固定する。

## 理由

- 数十行で書け、採用・不採用の理由を利用者に説明できる
- 制約は硬いものだけで、最適性より説明性が価値になる
- LLM は制約充足が不安定で、コマ衝突を起こす。理由づけだけを LLM に任せる

## 受け入れたトレードオフ

- 最適解ではない。高スコアの1科目が中スコアの2科目を塞ぐことがある
- 前提科目は制約にせず、理由文で案内するにとどめる

## 再検討する条件

- 必修の固定、科目区分ごとの最低単位、前提科目など制約が増え、貪欲法の結果が明らかに悪くなったとき。入出力の型を変えずに中身を整数計画へ差し替える
