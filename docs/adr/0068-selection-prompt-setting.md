# 0068. 選び直しの指示文を pair の SELECTION_PROMPT で替え、前と後を交互に比べる

- ステータス: 承認
- 日付: 2026-10-26

## 文脈

- `experiment pair` は前と後を職業と回の組ごとに交互に流して比べる(ADR 0055)が、替えられるのは設定だけで、指示文の違いは比べられない
- 指示文を変えて `experiment run` を続けて 2 回流すと、流した時刻の揺れが差に入る。同じ設定でも、別の時刻に流すと選んだ科目のうち関係なしが 9 ポイントほど動いた(ADR 0055)
- ADR 0065 では読み取りの指示文を、前の実装をファイルから読み込む使い捨ての道具で交互に測った。繰り返せず、確かめ用(ADR 0067)の道具の守り(結果の書き先、理由を隠す)も使えない
- 選び直しの指示文を直したい(ADR 0069)。直しの効き目は数ポイントの見込みで、時刻の揺れに埋もれる

## 検討した選択肢

1. 指示文を pair で替えられるようにする。`experiment pair` の `--before` と `--after` に `SELECTION_PROMPT=<ファイル>` を書くと、その側はファイルの文面で選び直し、書かなければ組み込みの文面を使う
2. `run` を続けて 2 回流す。コードは変えないが、時刻の揺れで数ポイントの差は見分けられない
3. ADR 0065 と同じく使い捨ての道具で交互に流す。リポジトリのコードは変えないが、繰り返せず、確かめ用の守りも使えない

## 決定

高橋さんが 1 を選んだ。

- `SELECTION_PROMPT` は本番の設定(`Settings`)には置かず、`experiment pair` の `--before` と `--after` でだけ書ける。実験の CLI がファイルを 1 度だけ読み、前後の空白を除いた文面をその側の選び手と結果の指紋に使う(流している間にファイルを書き換えても、使う文面と指紋はずれない。エディタが足す末尾の改行で指紋が変わらない)。ファイルが無い、読めない、空のとき、組み込みの文面の書き方(`{REASON_LIMIT}` や行末の `\`)が残っているときは、流す前に断る
- 書かなければ組み込みの文面(`openai_course_selector.py` の `INSTRUCTIONS`)を使う。組み立て(`presentation/composition.py`)の `course_selector` は指示文を受け取れ、受け取らなければ組み込みの文面を渡す。選び手は渡された指示文を使うだけ
- 最初は本番の設定に置き、環境変数を断る確かめを足したが、名前を小文字で書くと確かめをすり抜けて本番(API、worker、CLI)でも試した文面で選び直せるとレビューで分かった。試す文面は実験だけのものなので、設定から外した
- 結果の設定には、実際に使った文面の指紋を残す(今までどおり `prompts.selection`)
- 試した文面はリポジトリに置かない。組み込みの文面からの違いを ADR に書き、採った文面は組み込みの文面に入れる

## 理由

- 指示文の直しを、設定の直しと同じく交互に流して比べられる。時刻の揺れを差から除ける
- 確かめ用の道具の守り(ADR 0067)がそのまま効く
- 本番の入口(API、worker、CLI)からは試した文面を使えない。選び手は指示文を受け取るだけで、ファイルを読むのは実験の CLI なので、層の向きも変わらない

## 受け入れたトレードオフ

- `experiment run` では替えられない(続けて流す比べは時刻の揺れが入るので、pair だけにする)
- 試した文面は指紋と ADR の違いの説明でしか残らない
- 読み取りの指示文は替えられないまま(必要になったら同じ形で足す)

## 再検討する条件

- 読み取りの指示文も比べるとき
- 指示文の版をいくつも並べて比べたくなったとき(ファイルを並べる形が合わなくなる)
