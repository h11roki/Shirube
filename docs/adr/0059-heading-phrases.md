# 0059. 決まった文の見出しは、手で句に分けて並べる

- ステータス: 承認
- 日付: 2026-10-24

## 文脈

- 行先表示の板の折り返し(ADR 0058)を写真で確かめたとき、作成中の画面の見出し「道標を作っています」が、幅 320px で「道標を作っ / ています」と語の途中で折れていた。見出しは道しるべの絵と並ぶので幅が狭い
- 幅 320px と 375px の全ての画面の見出しを調べると、プライバシーポリシーの見出しも 320px で「プライバシーポリシ / ー」と折れ、行の頭に「ー」が来ていた
- トップの見出し(ADR 0046 のキャッチフレーズ)は、文を手で句に分け(`CATCHPHRASE`)、句ごとに inline-block の span で並べているので、どのブラウザでも句の切れ目で折れる。句の中には `PHRASE_WRAP`(`word-break: auto-phrase`)も付けているが、`auto-phrase` は Chromium だけが対応する
- この ADR の初めの版(同じ PR)は、トップの見出しが `PHRASE_WRAP` で句に折れていると読み違え、作成中の見出しに `PHRASE_WRAP` を付ける案を選んだ。レビューで、iPhone(どのブラウザも WebKit)では今のまま折れることが分かり、選び直した
- 句の並べ方で、見出しの読み上げの名前が変わる。Chrome の読み上げの木(DevTools Protocol の `Accessibility.getFullAXTree`)では、inline-block の句のあいだにも `<wbr>` にも空白が入り、「プライバシー ポリシー」になる。トップの見出しは前から「履修に迷ったら、 なりたい職業から。」だった。読み上げ専用の隠れた文(sr-only)と見えている文のあいだにも空白が入り、作成中の見出しは前から「データサイエンティストへの 道標を作っています」だった。読み上げ専用の文 1 つに名前を全て書き、見せる句を読み上げから外す(aria-hidden)と、名前は「プライバシーポリシー」のまま
- 切符の授業名と道のりの終わり(行き先)の見出しも語の途中で折れるが、中身が変わる見出しで、切符の欄の狭さも絡むので、別に決める

## 検討した選択肢

1. 決まった文の見出しは、トップの見出しと同じく手で句に分け、句の切れ目でだけ折る
2. `PHRASE_WRAP` を付けるだけ。Chromium だけが句で折る。「プライバシーポリシー」はカタカナの続く語で、auto-phrase では分けない
3. 中身が変わる見出しも含め、見出し全般に板と同じ語の切れ目の決まり(`Intl.Segmenter` と `<wbr>`)を使う
4. 見出しに `line-break: strict` を付ける。行の頭の「ー」は防げるが、幅 320px で「プライバシーポリ / シー」「道標を作っ / ています」と語の途中で折れるのは変わらない

## 決定

高橋さんが 1 を選んだ。

- 句を並べる部品(`Phrases`)を作り、トップ、作成中、プライバシーポリシーの見出しで使う
- 句のあいだに `<wbr>` を挟み、`word-break: keep-all` で句の中では折らない(行先表示の板と同じ作り、ADR 0058)。1 つの句が行より長いときだけ、`overflow-wrap: anywhere` で句の中で折る
- 見出しの読み上げの名前は、句をつないだ文を読み上げ専用の文 1 つ(sr-only)に書いて渡し、見せる句は読み上げから外す。作成中の見出しは、職業名の「〇〇への」もその文の頭に入れる(`spokenPrefix`)。初めは句を inline-block で並べ、読み上げにもそのまま渡していたが、レビューで名前に空白が入ると分かり、こうした
- 作成中の見出しは「道標を」「作っています」、プライバシーポリシーは「プライバシー」「ポリシー」に分ける。利用規約は 1 つの句
- 通しの試験で、3 つの見出しが幅 320px と 375px で、どの行も句をそのまま並べたものであること(句の途中で折れないこと)と、Chrome の読み上げの木の見出しの名前が句をつないだ文のままであることを確かめる。Playwright の名前の計算は `<wbr>` に空白を入れないので、Chrome の木を読む

## 理由

- `<wbr>` と `word-break: keep-all` はどのブラウザも対応するので、ブラウザによらず句の切れ目でだけ折れる。板と同じ作りなので、折る所を決める作りが 1 つで済む
- 決まった文なので、句は書く人が決められる
- 読み上げの名前を見せる句と分けると、句の並べ方によらず名前が変わらない

## 受け入れたトレードオフ

- 見出しの文を変えるときは、句の分け方も書き直す
- 1 つの句が行より長いと、句の中で折れる
- 見出しの文が DOM に 2 度入る(読み上げ用と見せる用)。結果の画面の見出し(読み上げ専用の見出しと、読み上げから外した行先表示の板)と同じ形
- 読み上げの名前の試験は Chrome の DevTools Protocol に頼るので、Chromium でだけ流せる。通しの試験は Chromium だけで流している
- 中身が変わる見出し(授業名、行き先)はこの決まりの外

## 再検討する条件

- 中身が変わる見出しの折り返しを決めるとき
- 新しい決まった文の見出しが語の途中で折れたとき
- Chrome が `<wbr>` を読み上げの名前に空白として入れなくなったとき(読み上げ用の文を分けずに済む)
