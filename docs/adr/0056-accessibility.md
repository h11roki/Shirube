# 0056. 画面をフォーカス、完成の知らせ、狭い画面の時間割、枠の色、文字と的の 5 つで WCAG 2.2 の AA に寄せる

- ステータス: 承認
- 日付: 2026-10-23

## 文脈

品質の点検で決めたテーマ A〜I のうち、テーマ E(アクセシビリティ)。WCAG 2.2 の AA を目安に、画面のコードを調べて次の 5 つが残っていた。

- 道のりの上の帯(車内の路線図の帯)は画面の上に貼り付き、高さが 62px ほど(行き先の職業名が折り返すと 90px ほど)ある。Tab で移った切符の中のリンクやボタン(シラバス ↗、乗換、もう取った)や、学期の時間割を開くリンクが帯の下に隠れうる(2.4.11)。右下の見た目の切り替えと、もう取ったのあとの知らせも下を覆う。ページに scroll-padding が無い
- 作成中の段は aria-live の枠で読み上げるが、完成すると作成中の画面ごと外れて結果に替わり、完成は何も伝えない。読み上げ、フォーカスの移動、タブの題のどれも無い(4.1.3)。失敗は role="alert" の知らせで伝わる
- 週の時間割表は幅 34rem の表で、幅 375px の画面では木と金が画面の外に出る。横に動かす入れ物はキーボードで入れず、名前も、右に続きがある手がかりも無い
- 枠の色 `--line` は、紙、シート、切符の背景との差が 1.25〜1.49 で、部品の境目に要る 3:1 に届かない(1.4.11)。入力欄(背景との差 1.08)、輪郭だけのボタン、見た目の切り替えの「切」(1.35)、学期のタブが見分けにくい。フォーカスの見た目はブラウザ任せで、入力欄は枠の色が変わるのと薄い輪(1.35)だけ
- 9.5〜11px の文字が多い(切符の半券のラベル 9.5px、未確定 10px など)。もう取った、戻す、取り消すのボタンは高さ 22px、フッターのリンクは 16px で、24 × 24px(2.5.8)に届かない

## 検討した選択肢

フォーカスが帯に隠れること

1. 上と下にスクロールの余白(scroll-padding と scroll-margin)を付け、Tab で移った部品をブラウザが余白の内側まで動かすようにする
2. 帯を貼り付けない。隠れないが、道のりのどこにいても路線図が見える働きを失う
3. 帯の下にフォーカスが入ったら帯を隠す。作りが大きい

完成の知らせ

1. 作成中から置いたままの読み上げの枠で完成を伝え、タブの題も作成中と完成で変える。フォーカスは動かさない
2. 読み上げの枠だけ。作りは一番小さいが、別のタブにいる人には届かない
3. 読み上げに加えて結果の見出しへフォーカスを移す。すぐ読めるが、待つあいだにほかの場所を操作していた人は位置を失う

狭い画面の時間割

1. 幅 640px 未満では曜日ごとの一覧にする。授業名が省かれずに読める。表と一覧の 2 つを描く
2. 表を縮めて 5 日を収める。曜日の幅が 50px ほどで授業名が切れる
3. 横に動かせる表のまま、キーボードで動かせて名前と手がかりを付ける。スマホでは横に動かさないと木と金が見えないまま

枠の色

1. 操作する部品の境目だけ、両方の見た目で 3:1 以上の新しい色にする。飾りの線は今の色のまま。フォーカスの輪は路線の色でそろえる
2. 枠の色そのものを 3:1 以上にする。切符や区切りも濃くなり、紙のようなやわらかい見た目が硬くなる
3. フォーカスの輪だけ直す。入力欄や切り替えの「切」が見分けにくいのは残る

文字と的

1. 押せるものは全て 24 × 24px 以上にし、11px 未満の文字を 11px にする
2. 文字も 12px 以上にする。帯や半券が大きくなり、帯が画面をより多く覆う
3. 的だけ直す

## 決定

高橋さんが、完成の知らせは 1、狭い画面の時間割は 1、枠の色は 1、文字と的は 1 を選んだ。フォーカスが帯に隠れることは、定番の直し方の 1 にする。

- 上の余白は、帯を出すときに道のりの駅とその中の要素へ scroll-margin で 7rem 付ける(帯の最も高いときと上の余白。帯から学期へ飛ぶときの `scroll-mt-28` と同じ)。帯が覆うのは道のりの中だけで、ページ全体に付けると、道のりの上にある見え方の切り替えへ飛ぶときにも空きができる。帯の行き先は 2 行までにして、帯の高さを 7rem の内に収める
- 下の余白は、ページ(`html`)に scroll-padding で 5rem 付ける(右下の見た目の切り替え)。もう取ったのあとの知らせは、幅の狭い画面で授業名が長いと 5rem を超えるが、出ているあいだはフォーカスが知らせの中にあり、6 秒で消える
- 結果の画面(`PlanView`)に、作成中から置いたままの読み上げの枠(role="status")を置き、作成中を見たあとに完成したら「道標ができました」と伝える。開いたときにもう完成していた道標では伝えない。失敗は今の role="alert" の知らせに任せる。タブの題は、作成中は「作成中: 道標 | shirube」、作成中を見たあとに完成したら「できました: 道標 | shirube」、失敗したら「作れませんでした: 道標 | shirube」にする。フォーカスは動かさない。題と読み上げの文は `src/lib/` の関数にして Vitest で確かめる
- 週の時間割は、幅 640px 未満では曜日ごとの一覧(曜日、時限、授業名、柱か礎)にし、640px 以上は今の表のまま。どちらも同じ並べ方の関数から作り、もう片方は CSS で隠す(隠した方は読み上げにも出ない)。授業の無い平日は「授業なし」とし、土日は授業があるときだけ出す
- 操作する部品の境目に新しい色 `--edge`(明るい見た目 `#8c8173`、暗い見た目 `#80766a`。紙、シート、切符の背景との差は 3.3〜3.9)を使う。入力欄と選ぶ欄、輪郭だけのボタン、見た目の切り替えの枠と「切」の溝、道のりと時間割帳の切り替え、学期のタブ。切符の縁、区切り線、空いたコマ、帯の縁、作成中の進みの線など飾りの線は `--line` のまま
- フォーカスは全ての部品で、路線の色(背景との差 6.3〜7.5)の 2px の輪を `:focus-visible` に付けてそろえる。入力欄の今の枠の色の変化と薄い輪はやめる。もう取ったのあとの知らせを置く、画面の幅いっぱいの見えない入れ物(スクリプトでフォーカスを移す先)には輪を付けない
- 押せる部品は全て 24 × 24px 以上にする(文の中のリンクは除く)。11px 未満の文字は 11px にする

## 理由

- WCAG 2.2 の AA の該当する項目(2.4.11、4.1.3、1.4.11、2.5.8)を満たし、狭い画面でも全ての授業が読める
- スクロールの余白は CSS だけで、帯の高さは行き先を 2 行までにすれば上限の 7rem の内に収まる
- 読み上げとタブの題は、画面を見ていない人や待つあいだに別のタブへ移った人にも届き、フォーカスを奪わない
- 一覧は授業名が省かれず、表の行と列の対応を読み上げで追う手間も無い
- 飾りの線は濃くしないので、紙のようなやわらかい見た目を保てる

## 受け入れたトレードオフ

- 余白のぶん、Tab で移ったときやページ内のリンクで飛んだときに上に空きができる
- 時間割を 2 通りに描く(並べ方の関数は共通)
- 輪郭だけのボタンと入力欄の枠が今より濃くなる
- 長い行き先は、帯では 2 行で切れる(行先表示と要約には全て出る)
- 半券のラベルなどが少し大きくなり、切符の風合いが少し変わる
- 自動のアクセシビリティの検査はまだ無く、今までどおり手で確かめる(ADR 0030)。幅 375px と 1280px、明るい見た目と暗い見た目、キーボードだけの操作と読み上げで確かめる

## 再検討する条件

- 押せる部品や枠を持つ部品を足すとき(同じ決まりで 24px と `--edge` を使う)
- 帯の高さが 7rem を超えるとき
- 自動の検査(axe など)を足すとき
