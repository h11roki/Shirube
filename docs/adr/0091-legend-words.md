# 0091. 路線図の言葉は替えず、凡例と乗換の欄に柱と礎と乗換が何かを一言添える

- ステータス: 承認
- 日付: 2026-11-05

## 文脈

- 結果の画面は路線図の見立てで、授業を「柱」と「礎」の判子つきの切符にし、礎から柱へのつながりを「乗換」と「乗り入れ」の欄で見せている(ADR 0033、0083、0086)。凡例は「柱の授業 / 礎の授業」だけで、柱と礎が何か、乗換が何を指すかは画面のどこにも書いていない
- ローンチ動画を作る中で、高橋さんから「電車や駅に寄せすぎず、なりたい職業に合う授業を取るという感じで」という指摘があった。動画の見出しは言い直したが、画面も初めて見る学生には「柱」「礎」「乗換」が何を指すか分からない
- 判子の字を読み上げにだけ残したとき(ADR 0083)、判子を知らない人には凡例と読み上げで補うとしていたが、凡例の言葉はそのままだった

## 検討した選択肢

1. 見た目と言葉はそのままに、凡例を「柱 職業に直結する授業 / 礎 柱の前提になる授業」に広げ、礎の切符の乗換の欄に「前提になる柱へ」、柱の切符の乗り入れの欄に「この柱を前提にする礎」の一言を添える
2. 結果の画面の先頭にある非公式の注意の文に、柱と礎と乗換の説明を 1 文足すだけにする
3. 判子に触れるか押すと説明が出るようにする
4. 「柱」「礎」「乗換」の言葉そのものを、「直結」「前提」「つながり」のような説明的な言葉に替える

## 決定

高橋さんが 1 を選んだ。

- 凡例の言葉は `RELEVANCE_DESCRIPTIONS`、欄の一言は `TRANSFER_HINT` と `ARRIVALS_HINT` に置き、凡例の見出し語と説明の間には読み上げにだけ区切り(「:」)を入れる
- 欄の一言はボタンの外に置いて乗換の欄の読み上げの名前(「乗換 [B] 柱の授業名 …」)は変えず、`aria-describedby` でボタンに結んで、キーボードで欄に着いた人にも届くようにする
- 凡例の印と見出し語は行頭にそろえ、狭い幅や文字を大きくした設定で説明が折り返しても印が行の間に浮かないようにする

## 理由

- 言葉を替えると、判子、系統の印、駅名標、方向幕と一体の見立て(ADR 0083、0086)が崩れる。見立ては残し、意味を一言で補えば、路線図を知らなくても読める
- 注意の文に足すだけでは、切符を読んでいるときに目に入らない。触れて出す説明は、気づかれにくく、スマホでは出しにくい
- 一言は 11px の 1 行で、切符の高さにほとんど響かない

## 受け入れたトレードオフ

- 乗り換えのある礎と柱の切符のそれぞれに同じ一言が付くので、道標が長いほど同じ文が繰り返される。1 行なので受け入れる
- README の結果の画面の画像は、凡例と欄の言葉が変わるたびに撮り直す

## 再検討する条件

- 利用者から、一言があっても柱と礎と乗換が分からないという声が出たとき(言葉そのものを替える 4 を考える)
- 切符の欄が増えて、一言の行が切符の高さに効いてきたとき
