# 0070. 文字 200% の試験は、ブラウザの既定の文字の大きさを 2 倍にして流す

- ステータス: 承認(px の文字は 0071 で rem にし、試験で 2 倍になる。縦の切れは字の大きさの 4 分の 1 までのはみ出しを許すようにした)
- 日付: 2026-10-26

## 文脈

- ADR 0056 で WCAG 2.2 の AA を目安にした。1.4.4(文字の大きさの変更)は、文字を 200% にしても中身と働きが欠けないことを求める
- 作成中の画面は、ブラウザの文字を 200% にすると幅 320px と 375px で横にはみ出していた。通しの試験で文字 200% を見ていたのは、決まった文の見出しが画面からはみ出さないかの試験(ADR 0059。html の font-size を 200% にする)だけだった
- 文字の大きくし方は 3 つある。ブラウザの文字の設定(既定の文字の大きさが変わる)、画面の拡大(px も含めて全てが大きくなり、CSS の幅が狭くなるのと同じ)、html の font-size を替える(試験の中でだけできる)
- rem のメディアクエリは html の font-size ではなく、ブラウザの既定の文字の大きさで決まる。html の font-size を 200% にすると、`sm:` や `md:` の切り替わりが動かないまま文字だけが倍になる。この試し方で幅 1280px の時間割帳の切符がはみ出すのを見つけて直したが、ブラウザの文字の設定ではメディアクエリも動いて狭い画面の並びになり、直しが無くてもはみ出さなかった
- Chromium は DevTools Protocol の `Page.setFontSizes` で、ブラウザの文字の設定と同じに既定の文字の大きさを替えられる。WebKit では替えられない

## 検討した選択肢

1. CDP の `Page.setFontSizes` で既定の文字の大きさを 2 倍にする(Chromium だけ)
2. html の font-size を 200% にする(どのブラウザでも流せる)
3. 文字の大きさは試験せず、画面の拡大に当たる狭い幅の試験だけに頼る

## 決定

1 を採る。

- 画面の一覧(`e2e/screens.spec.ts`)の全ての画面を、Chromium で既定の文字の大きさを 2 倍(16px と等幅の 13px を 32px と 26px)にして開き、幅 320px、375px、1280px で横にはみ出さないかを確かめる。測る前に html の文字が 32px になったかを確かめる
- 幅 1280px では、overflow を隠した要素の中身が横にも縦にもはみ出していないか(文字が切れていないか)も確かめる
- 見出しの試験(ADR 0059)は WebKit でも流すので html の 200% のまま残す。幅 320px と 375px でだけ流し、その幅ではどちらの試し方でも rem のメディアクエリが効かないので、並びは同じになる
- 試験で守れない直し(時間割帳の列の最小幅)は入れない

## 理由

- 利用者がブラウザの設定で文字を大きくしたときと同じ並びを確かめられる。html の 200% では、どのブラウザの設定でも起きない並びを直してしまう
- 1.4.4 が求めるのはふだんの画面での 200%。幅 320px で 200% はふだんの文字の幅 160px に当たり、1.4.10(幅 320px で横に流さず読める)を超える(375px も同じ)。文字の切れを幅 1280px でだけ見るのはそのため。横のはみ出しは、作成中の画面の直しを見張るために狭い幅でも確かめる
- 画面の拡大は CSS の幅が狭くなるのと同じで、幅 320px と 375px の試験が当たる

## 受け入れたトレードオフ

- px で書いた文字(`text-[11px]` など 22 か所)は、ブラウザの文字の設定でも試験でも大きくならない。試験は利用者が見るものと同じだが、その文字が 2 倍になったときの崩れは見ていない
- 試験は Chromium だけで流す。WebKit の文字の設定での崩れは見ない
- 幅 320px と 375px で文字を 200% にしたとき、切符の授業名(320px)と一覧の職業名(320px と 375px)が切れる。基準の外として扱う
- 隠していない箱からあふれて重なる文字は見ない。試しに見ると、字の上下の余白や切符の切り欠きの飾りなど、重なっていないものを全ての画面で拾った
- `Page.setFontSizes` は CDP の試験的な命令で、Chromium の版で変わりうる。測る前に html の文字の大きさを確かめるので、効かなくなれば落ちる

## 再検討する条件

- px で書いた文字を rem にしたとき(試験がその文字も見るようになる)
- `Page.setFontSizes` が使えなくなったとき
- 幅 320px と 375px で文字 200% にしたときの切れを直すと決めたとき
