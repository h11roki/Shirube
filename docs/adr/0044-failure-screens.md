# 0044. 画面の失敗は日本語の決まった形で知らせ、ログイン切れは 1 か所で受けてページを読み直す

- ステータス: 承認
- 日付: 2026-10-22

## 文脈

本番の前の点検(テーマ D、画面の壊れにくさ)で、無い URL は Next の既定の英語のページ(404: This page could not be found.)で、描けなかったときのページが無く、API の失敗の見せ方が画面ごとに違い、ログインが切れた(401)ときに「ログインし直す」のボタンがあるのは結果の画面だけで、一覧の読み込みに失敗すると読み直す手段が無いと分かった。

ログインの状態は Auth.js のクッキーにあり、Route Handler はクッキーが無いか切れていれば 401 を返す(ADR 0028)。ページは `LoginRequired` がサーバーでログインを確かめてから描く(ADR 0030)ので、ページを読み直せばログインの案内(同意の文つき、ADR 0042)に戻り、Google でログインすると同じページに帰る。

## 検討した選択肢

ログイン切れ(401)の受け方

1. 1 か所で受ける。`LoginRequired` の中の `SignedOutGate` が、どの呼び出しでも 401 が返ったらページの中身を「ログインが切れました」と「ログインし直す」に替える
2. fetch ごとに失敗の文とボタンを出す。同じ画面に知らせとボタンが何個も並び、送るボタンも押せたまま
3. 401 を受けたら自動でページを読み直す。入力中の内容が黙って消える

ログインし直す動き

1. ページを読み直す。同じ画面のログインの案内に戻り、ログイン後も同じ画面に帰る
2. `/login` へ移る。ログイン後は入力の画面へ移り、見ていた画面に戻らない

無い道標(404)

1. 「道標が見つかりません」と一覧への導線だけで、読み直すボタンは出さない
2. ほかの失敗と同じに読み直すボタンを出す(読み直しても見つからない)

## 決定

- 無い URL は `not-found.tsx`、描けなかったときは `error.tsx`(「もう一度試す」は `router.refresh()` と `reset()` でサーバーからも取り直す)、root layout が壊れたときは `global-error.tsx`(見た目の設定の script とフォントは root layout と共有し、ページごと読み直す)で、日本語で知らせてトップへの導線を置く
- API の失敗は `FailureNotice`(何を読めなかったかの文と、失敗の文、読み直すボタン)か、同じ文(`messageOf`)で出す。画面全体が知らせになる一覧は、読み直す前に知らせを消して「読み込んでいます」に戻す。画面の一部の知らせ(入力の画面のクラスの選択など)は結果が返るまで残し、送るボタンを止めない
- 全面の知らせの枠(危険色の section と見出し)は `Notice` で共有し、ページに h1 が残る場所では h2 にする
- `messageOf` は 401 だけの文を持たない。401 は `SignedOutGate` が先に中身を替えるので、その文が画面に出る道が無い
- ログイン切れは 1(1 か所で受ける)。API の呼び出しが 401 を受けたら `lib/api/client.ts` が購読者に知らせ、`SignedOutGate` が中身を替える。動きは 1(ページを読み直す)
- 無い道標は 1(読み直すボタンを出さない)

## 理由

- 401 は「セッションが切れた」という 1 つの状態で、fetch の数だけ知らせるものではない。中身を替えれば、そのあとの要求も送られない
- ページを読み直せば、ログインの案内と同意の文を経て同じ画面に帰れる。`/login` へ移ると見ていた道標に戻れない
- 404 の道標は読み直しても見つからず、ボタンは期待を裏切る

## 受け入れたトレードオフ

- 入力中の内容はページの読み直しで消える(ログインし直すのだから避けられない)
- backend だけが 401 を返す設定の誤り(frontend と backend の `AUTH_JWT_SECRET` の不一致など)では、読み直しても同じ知らせに戻る。本番化で鍵の一致を確かめる
- `error.tsx` の「トップへ」は、`/` 自身で起きた失敗では Next の境界が消えず効かないので、`/` では出さない(「もう一度試す」だけ)

## 再検討する条件

- ログイン切れを前もって知らせたいとき(セッションの残り時間を見て案内する)
- 入力中の内容を読み直しのあとも残したいという要望が出たとき
