# 0033. 道しるべを鉄道の見立てで深め、礎から柱への乗り換えを見せる

- ステータス: 承認
- 日付: 2026-10-19

## 文脈

ADR 0031 で、画面を道標の路線図に見立てた「道しるべ」にした。高橋さんは画面をもっと凝りたいと考え、方向性の案を 27 個まで描き比べた(駅と切符、和紙と朱印、地図と道、基板と回路、星図、多路線の地下鉄図、雑誌の特集、車窓、すごろく、乗換案内、発車標、ダイヤグラム、五重塔、木、積み木の街、御朱印帳、実験ノート、絵巻物、新聞の号外、スキルツリー、トレーディングカード、登山の断面図、ストーリーズ、ターミナル、プレイリスト、カンバン、ガントチャート)。そのうえで高橋さんは「このアプリのコンセプトを思い出して最適なデザインにして」と、どれにするかを Claude に任せた。

shirube は、なりたい職業(行き先)から、卒業までの学期ごとの時間割(道標)を組む。画面が伝えるべきことは 3 つある。

- 卒業までの道のり(どの学期に何を取るか)
- 学期ごとの週の時間割(履修登録の下書き)
- 授業を取る理由と、礎がどの柱を支えるか

今の画面は 1 と 2 を「道のり / 時間割帳」で見せているが、3 のうち礎 → 柱のつながりは「確率統計の礎」という文字でしか出ていない。見本の道標では、情報処理(データ構造とアルゴリズムの礎)が、その柱より後の学期に置かれている。前提科目は制約にしない(ADR 0007)ので起こりうるが、今の画面では気づけない。

## 検討した選択肢

1. 鉄道の見立てを深める(しるべ線): 学期を駅名標、授業を切符、礎 → 柱を乗り換え、卒業を記念スタンプの押された終着駅にし、上に行先表示と乗換案内のような要約を置く
2. 建てる見立て(五重塔、木): 礎石の上に柱が立つ、根から幹が伸びる
3. 図で見せる(基板と回路、ダイヤグラム、ガントチャート、星図): 礎 → 柱を線で結ぶ
4. 紙もの、遊び、デジタルの見立て(御朱印帳、雑誌、スキルツリー、ストーリーズなど)

## 決定

選択肢 1 にした。高橋さんに任されて Claude が選び、理由をここに残す。マージの前に高橋さんが画面で確かめる。

結果の画面

- 見出しは電車の行先表示のような濃い板に「〇〇 行」と出し、その下に乗換案内のような要約(出発の学期 → 卒業の年月、所要の学期の数、計の単位、柱と礎の数)を並べる。見出しの読み上げは「〇〇への道標」のまま
- 学期は駅名標にする。駅番号(SH01 から)、学期名、読み、前と次の学期を書く。最初の駅は「出発」とする(作った後に見返すので「現在地」とは書かない)
- 授業は切符にする。左に役割、科目名、理由、右の半券にコマ、クラス、単位を欄として並べる。柱の切符には朱の丸印を押す
- 礎の切符には「乗換 → 柱の科目名(その学期)」を書き、柱より後の学期に置かれた礎には「柱より後の学期です」と注意を出す
- 卒業は終着駅にし、記念スタンプ(しるべ線、卒業、年月)と、通った単位と柱と礎の数を出す
- 時間割帳は今の形(タブ、付箋の週の時間割、理由のカード)のまま、タブに駅番号を添える
- 作成中の画面とログイン前の紹介も、行先表示と駅名標にそろえる
- 卒業の年月、駅番号、学期の読み、乗り換え(礎 → 柱、柱より後か)は lib に置いて確かめる

## 理由

- 鉄道は、卒業までの道のり(路線)と学期ごとの時間割(時刻表、ダイヤ)の両方を一つの見立てで表せる唯一の案で、shirube が見せる 2 つの見え方とそのまま重なる
- 礎 → 柱を「乗り換え」と読むと、つながりの向きと学期の前後が言葉で書け、柱より後の学期に置かれた礎という、今は見えない情報を出せる
- 駅名標と切符は誰でも読み方を知っていて、説明が要らない。切符の欄は、コマ、クラス、単位という履修登録に要る値の置き場としてそのまま使える
- ADR 0031 の路線図を作り直すのではなく深めるので、部品の差し替えで済む
- 建てる見立ては柱と礎の言葉には合うが、学期を進む時間が出ない。図の見立ては情報は多いが、毎日見返す画面としては読み方の説明が要る。紙もの、遊び、デジタルの見立ては、飾りが情報より前に出るか、進路の重みが軽く見える

## 受け入れたトレードオフ

- 切符の半券の分だけ、カードが横に場所を取る
- 鉄道に寄せすぎると子どもっぽく見えるので、色は今の朱と藍、地は紙のままにする
- 乗り換えは、選び直しが返す「前提にする柱」だけを表す。礎が複数の柱を支える関係は表せない

## 再検討する条件

- 利用者が切符の欄を読みにくいと感じたとき
- 礎が複数の柱を支える関係を推薦が返すようになったとき
- 時間割帳の方がよく使われると分かったとき(既定の見え方を変える)
