# 0009. 本番は EC2 1台で docker compose を動かす

- ステータス: 承認
- 日付: 2026-10-14

## 文脈

個人開発で固定費を抑えたい。AWS の無料枠は 2025年7月以降の新規アカウントでクレジット制(6か月)になっている。

## 検討した選択肢

| 構成 | 月額目安 |
|---|---|
| EC2 1台 + docker compose | $15〜25 |
| ECS Fargate + RDS + ALB | $50〜90 |
| Amplify Hosting + Lambda + Aurora Serverless v2 | $0〜20 |

## 決定

EC2 1台でローカルと同じ compose を動かす。設定は環境変数で渡し、アプリはステートレスに保ち、DB は compose 内の PostgreSQL をボリュームで永続化する。

## 理由

- 最も安く、ローカルの compose と同じ構成でそのまま動く
- Fargate は ALB と NAT の固定費が重く、IaC の学習も要る
- サーバーレスはコールドスタートと API Gateway の 29 秒制限があり、同期 API と相性が悪い

## 受け入れたトレードオフ

- 単一障害点。OS 更新と pg_dump のバックアップを自前で持つ
- スケールアウトは手動

## 再検討する条件

- 利用者が付き、停止が許容できなくなったとき。環境変数とステートレス設計を守っていれば、Fargate + RDS への移行は構成変更で済む
