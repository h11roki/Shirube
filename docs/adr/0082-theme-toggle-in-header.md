# 0082. 見た目の切り替えは、画面の隅に固定せずヘッダーに置く

- ステータス: 承認
- 日付: 2026-10-31

## 文脈

- ADR 0031 で、明るい見た目を既定にし、画面の隅の「ダークモード」のボタンで切り替えると決め、右下に固定して置いた
- 幅 375px でスクロールすると、このボタンが切符の文字や学期の見出しの上に重なる。README の画像を撮るときに見つかった
- 重なりを避けるため、フッターの下に余白を取り、html の下に scroll-padding(5rem、ADR 0056)を付けていたが、スクロールの途中の重なりは消えない。axe もボタンに覆われた文字の色の差を判定できず、e2e では手で測った文字の一覧に入れて通していた

## 検討した選択肢

1. ヘッダーのロゴの行の右端に置く
2. フッターに置く
3. 隅のまま、狭い幅では文字を消した丸いボタンにする

## 決定

高橋さんが 1 を選んだ。

- 幅 640px 未満では、ロゴの行の右端に置き、ナビは次の行に回す。640px 以上では、ナビの右に並べる
- 見た目は今の文字つきのスイッチのまま(「ダークモード」の文字と、押したかを伝える aria-pressed)。固定、影、半透明の背景はやめる
- フッターの下の余白は、右下のボタンを避けるためだけに取っていたのでやめる。html の下の scroll-padding は、画面の下に固定する「もう取った」のあとの知らせのために残す(ADR 0056)

## 理由

- どの幅でも、どの部品にも重ならない。どのページでも上の決まった場所で見つかる
- フッターは下まで下ろさないと見つからない。丸いボタンは重なる面積が減るだけで、スクロールの途中は切符の上を通り続ける

## 受け入れたトレードオフ

- ページの下の方を読んでいるときは、切り替えるのに上まで戻る
- ヘッダーの部品が 1 つ増える。狭い幅で文字を大きくすると、ロゴの行に入りきらず、切り替えが次の行に回る

## 再検討する条件

- ヘッダーに部品が増え、狭い幅で 3 行を超えるとき
