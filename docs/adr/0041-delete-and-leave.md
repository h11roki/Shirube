# 0041. 道標は中身を消して作った日時だけを翌日まで残し、退会では利用者と覚えを消して道標の日時だけを持ち主なしで残す

- ステータス: 承認
- 日付: 2026-10-21

## 文脈

本番は誰でも Google でログインして使える公開にする(ADR 0038)。本番の前の点検で、道標も、もう取った授業の覚えも、利用者そのものも消せないと分かった(覚えた授業を 1 つずつ取り消すことだけはできる。ADR 0035)。保存しているのは、Google の sub、入力した職業、道標、もう取った授業(履修の記録に近い)で、利用者が自分で消せることと、その方法をプライバシーポリシーに書くことが要る。

一方、道標の受け付けは、道標の表をその日の分だけ数えて 1 人 1 日 3 件、全体で 1 日 30 件に限る(ADR 0038)。道標を行ごと消せるようにすると、消して作り直せば上限を越えられる。

## 検討した選択肢

道標の消し方

1. 中身(職業、推薦、配置、失敗の文)を消し、「削除済み」と作った日時だけを残して、その日の上限に数える
2. 行ごと消す
3. 退会だけ作り、道標ごとには消せない

残した日時の消し方

1. 次の日に worker が消す
2. ずっと残す

退会したときの道標(PR のレビューで足した)

1. 中身を消し、持ち主を外した日時だけを翌日まで残して、全体の上限に数える
2. 行ごと全て消す

作成中(worker が作っている途中)の道標(PR のレビューで足した)

1. 消せない(待ちの道標は消せる)
2. 消せるが、作り終わるまで作成中の 1 件に数える

消すボタンと退会の入口、消す前の確かめ方は、画面の PR で決めた(結果の画面と一覧の両方、退会は一覧の下、その場でもう一度押してもらう)。

## 決定

高橋さんが選んだ。消し方は 1、日時は 1、退会は 1、作成中は 1。退会と作成中は、初めは「全て消す」「消せる」としていたが、PR のレビューで、退会と入り直しを繰り返すと全体の上限まで外れて費用の上限が無くなること、作成中の道標を消すと worker が作り続けたまま次を送れて作成中の 1 件の上限を越えられることが分かり、選び直した。

- `DELETE /api/v1/plans/{id}` は、自分の道標を「削除済み」にし、条件、結果、失敗の文、段、作り始めた日時と終えた日時を消して、利用者の内部の ID と作った日時だけを残す(204。無いか他人の道標は 404)。待ちの道標は消せる。作成中の道標は 409 で「作っている途中の道標は、できてから消せます」と断る
- 失敗した道標を消すときは、持ち主も外す。失敗は 1 人の上限に数えず全体の上限にだけ数える(ADR 0038)ので、消したあとも同じ数え方になる
- 削除済みの道標は、どの読み出し(一覧、取得、もう取ったの答え)にも出さない
- 受け付けの上限は、削除済みの道標も数える。持ち主のあるものは 1 人の上限にも、持ち主の無いものも含めて全体の上限にも入る
- worker は、日本時間で日が変わったら、その日より前に作った削除済みの道標を消す(繰り返しのたびには消さない。消すのに失敗しても道標づくりは止めない)
- `DELETE /api/v1/me` は、利用者の道標を全て削除済みにして持ち主を外し(作った日時だけが残り、翌日に worker が消す。全体の上限に数える)、そのあと利用者を消す(204)。もう取った授業の覚えは外部キーの ON DELETE CASCADE で利用者と一緒に消える。道標の外部キーは ON DELETE SET NULL で、持ち主の無い行は削除済みでなければならない(制約で守る。中身の残った道標がある利用者は消せない)。同じ Google のアカウントで次にログインすると、新しい利用者として始まる
- 道標の表の `conditions` は、削除済みのときだけ NULL にできる(制約で守る)

## 理由

- 中身を消せば、職業や履修の記録は残らず、作った日時は上限を数える間だけ残る。消して作り直しても上限は越えられない
- 次の日には日時も上限に要らないので消せる。プライバシーポリシーに「消した道標は、作った日時だけを翌日まで残す」と書ける
- 退会で残すのは持ち主の分からない作った日時だけなので、個人の記録は残らず、全体の上限(費用の上限)は退会と入り直しでも守られる
- 作成中の道標は数十秒でできるので、できてから消してもらえば足りる。消せるようにすると、無駄な OpenAI の呼び出しと、作成中の 1 件の上限のすり抜けが起きる

## 受け入れたトレードオフ

- 作成中の道標は、できるまで消せない(ふつう 10〜30 秒)
- 退会して同じアカウントで入り直せば、その日の 1 人の上限は 0 から数え直しになる(全体の上限で止まる)
- 退会と道標の削除は 2 つのトランザクションに分かれる。道標を消したあと利用者を消すのに失敗すると、道標だけが消えた状態になる(もう一度退会すれば終わる)
- worker が止まっている間は、前の日の削除済みの道標の日時も残る
- 道標の表の行の形が、削除済みとそれ以外で変わる(読み出しは削除済みを除く決まりを守る)

## 再検討する条件

- 消した道標を元に戻したいという声が出たとき
- 退会と入り直しで上限を越える使い方が目立ったとき(Google の sub ごとに数える記録を別に持つ)
